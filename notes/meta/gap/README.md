# GAP scripts — BG Appendix C, Problem 1 (Péterfalvi), `p = 3`

[issue 0180](../../../issues/closed/0180-bg-appc-problem1-p-eq-three.md) の計算機探索の再現用。
GAP は `~/gap-4.16.0/gap` (apt 版ではなくホーム直下のビルド、4.16.0)。

## 何を計算しているか

**還元 (紙で検証済、issue 0180 参照)**: `p = 3`, 素数 `q` について

> (B) が成立 ⟺ `H = P⋊U` を含む群 `G` と位数 3 の元 `g ∈ N_G(U)` が存在して、
> `⟨x,g⟩` が可換 `3′` 核・補群 `C₃` の**有限 Frobenius 群** `D` になる

さらに `G = ⟨H, g⟩` は融合積 `H *_U L` (`L = U⋊⟨g⟩`) の商なので、`D` の表示を課した
有限表示群 `Γ` の合同枚挙 (Todd–Coxeter) で**完全に判定できる**。

`q = 3` では探索対象が有限リストの直積になる:

| 軸 | 個数 | 中身 |
|---|---|---|
| `D` | 5 (位数 ≤ 60) | `A₄`, `C₇⋊C₃`, `C₁₃⋊C₃`, `(C₄×C₄)⋊C₃`, `C₁₉⋊C₃` |
| 生成対 `(x,g)` | `Aut(D)`-軌道代表 | `dsearch.g` が列挙 |
| `g` の `U ≅ C₁₃` への作用 | 3 | `u ↦ u`, `u ↦ u³`, `u ↦ u⁹` |

⚠ `x` の取り方は任意でよい — `U` は `P` の 13 本の `𝔽₃`-直線に推移的に作用するので、
`P₀` の選び方は共役を除いて一意。

## ファイル

| ファイル | 内容 |
|---|---|
| `dsearch.g` | 候補 `D = A⋊C₃` (`A` 可換 `3′`, f.p.f.) と生成対の列挙 |
| `one.g` | 1 ケース分。`DID1`/`DID2`/`PAIRIDX`/`UEXP` を `sed` で置換して使う |
| `drive.sh` | 全ケースを独立プロセス + 300s タイムアウトで駆動 → `cases.log` |
| `lib.g` | 具体的な有限群 `G` を直接テストする版 (`FindBorels` / `FindWitness` / `TestGroup`) |
| `cases.log` | 2026-08-09 の実行結果 |

```bash
cd notes/meta/gap && ./drive.sh && cat cases.log
```

## 結果 (2026-08-09)

24 ケース中 **9 ケースが否定で確定**、15 ケースはタイムアウト (**未決**、無限とは限らない)。

確定したケースでは `Γ` が必ず潰れ、`H` が埋め込まれない:
`|Γ| = 13` (`uexp = 1`) または `|Γ| = 1` (`uexp = 3, 9`)。

⚠ タイムアウトを「不可能」と読まないこと。合同枚挙が終わらないだけで、
`Γ` が無限か、単に枚挙が重いだけかは判定できていない。
