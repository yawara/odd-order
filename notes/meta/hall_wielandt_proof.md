## 定理

`G` 有限群、`p` 奇素数、`P ∈ Syl_p(G)`、`A ≤ P` が `G` に関し `P` 内で弱閉
(`∀ g, A^g ≤ P → A^g = A`)、`A` 可換。`N := N_G(A)` とすると

```
P ∩ G' = P ∩ N'.
```

(Tate の定理で `G/O^p(G) ≅ N/O^p(N)` に格上げできるが、**本 repo の消費点は focal 版で足りる**。)

記法: `x^g = g⁻¹ x g`。指標は加法的、値は有限可換 p-群 `C`。

## §1 弱閉性の即時の帰結

`u ∈ P` なら `A^u ≤ P^u = P` ゆえ弱閉性から `A^u = A`。したがって

```
A ⊴ P,   P ≤ N,   P ∈ Syl_p(N),   p ∤ [G:P].
```
`D := P ∩ N'` とおくと `P' ≤ D ⊴ P` で `P/D` は可換 p-群。
`D ≤ P ∩ G'` は自明なので、**逆の包含 `P ∩ G' ≤ D` を示せばよい**。

## §2 指標 transfer と二重剰余類公式

`T_H^K(χ)(k) = Σ_{t∈T} χ(h(t,k))` (`tk = h(t,k)·(t·k)`, `T` は横断集合)。
これは mathlib の `MonoidHom.transfer` そのもの。推移律 `T_S^K = T_H^K ∘ T_S^H`
は repo の `transfer_transfer` (landed)。

`R ≤ P` とし `G = ⊔_i P g_i R` (二重剰余類)、`S_i := R ∩ g_i⁻¹ P g_i`、
`U_i` を `S_i` の `R` 内横断集合とすると

```
T = { g_i u : i, u ∈ U_i }     は P の G 内横断集合         (9)
```
であり、`λ : P → C` に対し `λ_i(s) := λ(g_i s g_i⁻¹)`、`δ_i := λ_i − λ|_{S_i}` とおくと

```
T_P^G(λ)|_R = Σ_i T_{S_i}^R(λ_i)                              (13)
T_{S_i}^R(λ|_{S_i})(r) = [R:S_i]·λ(r)                          (14)
[G:P] = Σ_i [R:S_i]                                            (15)
⟹  T_P^G(λ)(r) − [G:P]·λ(r) = Σ_i T_{S_i}^R(δ_i)(r)   (r ∈ R)  (17)
```
(14) は `ur = s_{i,u}(r)u'` から `λ(s) = λ(u)+λ(r)−λ(u')` とし、`u ↦ u'` が `U_i` の
置換であることから和で `λ(u)`, `λ(u')` が相殺することによる。**これが唯一の大域公式**。

## §3 奇素数の局所 transfer 補題 (p > 2 はここだけで効く)

`X_R(x) := { (x^{p k})^r : k ∈ ℤ, r ∈ R }` (= `⟨x^p⟩` の `R`-共役の**合併**)。
非自明元の位数は `|x|` より真に小さい。

> **補題.** `R` 有限 p-群 (`p` 奇)、`A ⊴ R` 可換、`R = ⟨A, x⟩`、`S ≤ R`、
> `δ : S → C` 準同型。`T_S^R(δ)(x) ≠ 0` かつ `X_R(x) ∩ S ⊆ ker δ` なら `S = R`。

**証明.** `S < R` とし極大 `M ⊇ S` を取る (`M ⊴ R`, `[R:M] = p`)。`μ := T_S^M(δ)`。
推移律で `T_M^R(μ)(x) = T_S^R(δ)(x) ≠ 0`。

*(24)* `X_R(x) ∩ M ⊆ ker μ`: `z ∈ X_R(x) ∩ M` に対し `S\M` を `z` の右乗法の軌道に
分割。長さ `ℓ` の軌道 `St, Stz, …, Stz^{ℓ-1}` では最後だけ係数が非自明で
`t z^ℓ t⁻¹ ∈ S`。`X_R(x)` は冪と `R`-共役で閉じるので `t z^ℓ t⁻¹ ∈ X_R(x) ∩ S ⊆ ker δ`。
各軌道の寄与が 0 ゆえ `μ(z) = 0`。

*Case 1* `x ∉ M`: 横断集合 `1, x, …, x^{p-1}` で `T_M^R(μ)(x) = μ(x^p)`、
`x^p ∈ X_R(x) ∩ M` ゆえ (24) から 0 — 矛盾。よって `x ∈ M`。

*Case 2* `x ∈ M`: `A ⊄ M` (でなければ `R = ⟨A,x⟩ ≤ M`) なので `y ∈ A ∖ M` を取る。
横断集合 `1, y, …, y^{p-1}`。`x ∈ M ⊴ R` より各剰余類 `My^j` は `x` の右乗法で固定され

```
T_M^R(μ)(x) = Σ_{j=0}^{p-1} μ(y^j x y^{-j}).                    (28)
```
`B := M/M'`、`α :=` (`y` による共役の誘導自己同型)、`b := xM'`、`μ̄ : B → C` とすると

```
T_M^R(μ)(x) = μ̄((1 + α + ⋯ + α^{p-1}) b).                       (29)
```
`(y^j x y^{-j})^p = y^j x^p y^{-j} ∈ X_R(x) ∩ M` と (24) から `p·μ̄(α^j b) = 0`。
`ℤ[t]` で `1 + t + ⋯ + t^{p-1} = (t−1)^{p-1} + p·q(t)` (mod p で
`(t^p−1)/(t−1) = (t−1)^{p-1}`) なので

```
T_M^R(μ)(x) = μ̄((α − 1)^{p-1} b).                               (32)
```
ここで `c := y x y⁻¹ x⁻¹ = y·(x y⁻¹ x⁻¹) ∈ A` (両因子が `A`、`A ⊴ R`) かつ `c ∈ M`
(`x ∈ M ⊴ R`)。`y, c ∈ A` 可換なので `α` は `cM'` を固定 ⟹ **`(α−1)² b = 0`**。
**`p > 2` ⟹ `p−1 ≥ 2`** ゆえ `(α−1)^{p-1} b = 0`、すなわち `T_M^R(μ)(x) = 0` — 矛盾。∎

**p = 3 版の短縮**: `1 + α + α² = (α−1)² + 3α` (単なる恒等式) なので、
多項式の mod p 議論が不要になる。

## §4 主証明

`P ∩ G' ⊄ D` と仮定し、`x ∈ (P ∩ G') ∖ D` を**位数最小**に取る。
`C := P/D`、`λ : P → C` を商写像 (`ker λ = D`, `λ(x) ≠ 0`)。`R := ⟨A, x⟩` (`A ⊴ R`)。

- `τ := T_P^G(λ)` は可換群への準同型ゆえ `G'` 上消える。`x ∈ G'` より `τ(x) = 0`。
- `C` は p-群で `p ∤ [G:P]` ゆえ `[G:P]·λ(x) ≠ 0`。
- (17) を `x` で評価: `−[G:P]λ(x) = Σ_i T_{S_i}^R(δ_i)(x)` ⟹ ある `i` で
  `T_{S_i}^R(δ_i)(x) ≠ 0`。以下 `g := g_i`, `S := S_i`, `δ := δ_i`。
- **核条件**: `z ∈ X_R(x) ∩ S`, `z ≠ 1` なら `|z| < |x|` かつ `z ∈ P ∩ G'` ゆえ
  最小性から `z ∈ D`、`λ(z) = 0`。また `g z g⁻¹ ∈ P ∩ G'` で同位数ゆえ同様に
  `∈ D`、`λ(g z g⁻¹) = 0`。よって `δ(z) = 0`、すなわち `X_R(x) ∩ S ⊆ ker δ`。
- 補題 ⟹ **`S = R`** ⟹ `R ≤ g⁻¹ P g` ⟹ `A^{g⁻¹} ≤ P` ⟹ (弱閉性) `A^{g⁻¹} = A`
  ⟹ **`g ∈ N`**。
- すると `s ∈ S = R ≤ P ≤ N` と `g ∈ N` から `(g s g⁻¹)s⁻¹ ∈ N'` かつ `∈ P`
  ⟹ `∈ P ∩ N' = D = ker λ` ⟹ `δ(s) = 0` (∀ s) ⟹ `T_S^R(δ)(x) = 0` — 矛盾。∎

## 検証メモ (2026-07-26, Claude)

全ステップを独立に追跡し、以下を確認した:

- §1 の `A^u ≤ P` は `A ≤ P` と `u ∈ P` から `A^u ≤ P^u = P` ✓。
- (14) の相殺、(15) の数え上げ、(17) の差分 ✓。
- (24) の軌道分割で「最後の代表元のみ係数が非自明」 ✓、`X_R(x)` が冪・共役で閉じる ✓。
- Case 1 の `x^p ∈ M` (`[R:M] = p`) ✓。
- Case 2: `c = yxy⁻¹x⁻¹ ∈ A ∩ M` ✓、`α(cM') = cM'` (`A` 可換) ✓ ⟹ `(α−1)²b = 0` ✓。
- `1 + t + ⋯ + t^{p-1} ≡ (t−1)^{p-1} (mod p)` ✓ (𝔽_p で `(t^p−1)/(t−1)`)。
- `p = 3`: `(α−1)² + 3α = α² + α + 1` ✓。
- §4 の位数最小性の使い方 (`z` と `gzg⁻¹` の両方に適用) ✓、
  `A^{g⁻¹} ≤ P` の向き ✓、最後の `δ ≡ 0` ✓。

**Alperin の融合定理・Grün 第二定理 (Z(P) 版)・Burnside 融合はいずれも使っていない** ✓
(Gorenstein p.257 の注記と整合)。`p > 2` は `(α−1)^{p-1}` の指数のみで効く ✓。

## 副問の回答 (本 First Case への適用)

- 本件の追加構造 (`P = C_G(Z(P))`, `|Z(P)| = 3`, `class(P) = 3`, `A ≅ C₃³`) は
  **不要**。`A` 弱閉 + 可換だけで上の定理が使え、`N_G(A) = N_G(P)` から
  「`N_G(P)` が 3-transfer を制御する」が出る。
- `N_G(P) = N_G(Z(P))` から `Z(P)` の弱閉性は**出ない** (`Z(P)^g ≤ P` は
  `P ≤ C_G(Z(P)^g)` を含意しない) — 我々の解析と一致。
- 我々の局所形状 (class 3, `A ≅ C₃³`, `|Z| = 3`) は `C₃≀C₃` と**両立する**ので、
  Yoshida の例外を排除できないのも当然 — これも我々の解析と一致。
- `[N_G(P) : P] ≤ 2` (`N_G(Z(P))/C_G(Z(P)) ↪ Aut(C₃) = C₂`) — landed の
  `N_G(Z₁) = R₂⟨s⟩` と整合 (sanity check 合格)。
