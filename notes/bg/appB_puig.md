## Puig L(S) の定義と直感

### 記号と定義

**Rel-relation X→Y** (L4532): Y is generated by abelian subgroups **all normalized by X**.

```
X → Y :⟺ 
  Y = ⟨A : A abelian subgroup, X ≤ N_G(A)⟩
  
L_G(X) := max{Y : X → Y}  (unique largest such Y)
```

### L_n(G) 再帰 (L4534-4542)

```
L_0(G)       := 1
L_{n+1}(G)   := L_G(L_n(G))    [= max Y s.t. L_n(G) → Y]

L(G)  := ⋂_{n≥0} L_{2n+1}(G)   [odd indexed limit]
L_*(G) := ⋃_{n≥0} L_{2n}(G)    [even indexed limit]
```

### 二者択一図

```
L_0(G) ⊆ L_2(G) ⊆ L_4(G) ⊆ ... ⊆ L_*(G)
  ↓       ↑       ↓                    ↑
  └──────┘       └────────────────────┘
       (↔ 双対)
  
L_1(G) ⊇ L_3(G) ⊇ L_5(G) ⊇ ... ⊇ L(G)
```

Lem B.1(b)-(c)-(d): **L_*(G) は increasing chain の limit** (finite で stabilize), **L(G) は decreasing chain の limit** (finite で stabilize), both are subgroups.

### J(S) との比較

| 性質 | Thompson J(S) | Puig L(S) | 差分 |
|------|---------------|-----------|------|
| 定義 | maximal elem abelian の生成 | odd-index L_n の交 | J = L (odd solvable 下での等価) |
| 計算 | direct (P 内 maximal) | 再帰 (L_n iteration) | L は more general (arbitrary group) |
| 特徴 | char P (char subgroup of P) | char G (さらに強い) | char P より char G が有力 |
| p-group G での性質 | Z(J(G)) ≠ 1 if G ≠ 1 | Z(L(G)) ≠ 1 (same) | 同じ | 
| 奇数 solvable | J(S) = Z(J(S))·O_{p'}(G) ⊴ G (Isaacs Thm 7.6) | L(S) = Z(L(S))·O_{p'}(G) ⊴ G (Thm B.4) | **互換 (奇数 solvable 下)** |

## Lem B.1 (L_n の基本 7 性質) 詳解

### (a) Antimonotonicity of L_G(−)

```
X ⊆ Y ⇒ L_G(X) ⊇ L_G(Y)
```

**直感**: X が小さい ⇒ X と compatible な abelian がより多い ⇒ L_G(X) が大きい.

### (b) Stabilization chains

```
1 = L_0(G) ⊆ L_2(G) ⊆ L_4(G) ⊆ ... ⊆ L_5(G) ⊆ L_3(G) ⊆ L_1(G) = G
```

**直感**: 偶数列は up, 奇数列は down. 両 limits に収束.

### (c)-(d) Stabilization + subgroup structure

G finite ⇒ ∃k s.t.
```
L_{2n}(G) = L_*(G)  (all n≥k, stable even)
L_{2n+1}(G) = L(G)  (all n≥k, stable odd)
L_*(G) ⊆ L(G) ⊆ G
L_*(G) is subgroup of G
```

**形式化ポイント**: `Subgroup.iInf` と `iSup` の limit 存在と等号. Finite だから stabilize する (monotone + bounded).

### (e) Abelian normal subgroups

```
A ⊲ G, A abelian ⇒ A ⊆ L_i(G)  (all i > 0)
```

**直感**: abelian normal は最初の step L_1 で self-relation より L_G(1) = L_1 に入り, その後も descend/ascend しても消えない.

### (f) p-group の自己中心性

```
G p-group, i > 0 ⇒ 
  L_i(G) ⊇ C_G(L_i(G)) ⊇ Z(G)
  L_*(G) ⊇ C_G(L_*(G)) ⊇ Z(G)
  L(G) ⊇ C_G(L(G)) ⊇ Z(G)
  ⇒ L_*(G) ≠ 1, L(G) ≠ 1 (if G ≠ 1)
```

**直感**: p-group ⇒ abelian maximal normal が常に存在. その centralizer は itself に included. 結果として L_i が "self-centralizing" に近い.

### (g) Duality identity

```
L_G(L_*(G)) = L(G)  [and L_G(L(G)) = L_*(G)]
```

**直感**: L_* (even limit) と L (odd limit) は互いに上下関係を規定する対偶性.

## Lem B.2 (Relative L-stability)

```
H ⊇ L(G) ⇒ L(H) = L(G)
```

**証明思路 (2 Step)**:
1. **下から**: L_{2n+1}(H) ⊆ L_{2n+1}(G) (by induction + inclusion H ⊇ L(G) ⇒ L(G) ⊆ H so compatible abels)
2. **上から**: L(G) ⊆ L_{2n+1}(H) (same H ⊇ L(G) condition で逆向き induction)

**形式化**: Subgroup の包含条件が L-limit を保存する properness 証明.

## Lem B.3 (Odd solvable 下での Sylow-pcore 階層)

```
Assume: p odd, G solvable odd, O_{p'}(G)=1, S ∈ Syl_p(G), T := O_p(G)
Then:  L_*(S) ⊆ L_*(T) ⊆ L(T) ⊆ L(S)
```

### 証明構造 (induction on n)

**目標**: L_{2n}(S) ⊆ L_{2n}(T) ⊆ L_{2n+1}(T) ⊆ L_{2n+1}(S)

**base (n=0)**: 1 ⊆ 1 ⊆ T ⊆ S (自明)

**step (n → n+1)**:
1. L_{2n+1}(S) → L_{2n+2}(S) (定義)
2. L_{2n+1}(T) → L_{2n+2}(S) (L_{2n+1}(S) → part より)
3. **Key**: L_{2n+1}(T) ⊲ G ∧ L_{2n+1}(T) p-group (by construction)
4. **Lem B.1(f)**: L_{2n+1}(T) ⊇ C_T(L_{2n+1}(T)) (p-group property)
5. **Thm A.5** (Rel part): C_G(Y) を Y=L_{2n+1}(T) で適用, X = L_{2n+2}(S) (L_{2n+1}(T) が normalized) ⇒ L_{2n+2}(S) ⊆ T
6. **結論**: L_{2n+2}(S) ⊆ T ∧ L_{2n+1}(T) → L_{2n+2}(S) ⇒ L_{2n+2}(S) ⊆ L_{2n+2}(T)

### App.A Thm A.5 との接続点

**L4666** (Lem B.3 proof Step 2):
```
... thus, by (B.2) and Theorem A.5,
L_{2n+2}(S) ⊆ T
```

A.5(2)の条件: 
- P = L_{2n+1}(T) normal ✓
- X = L_{2n+2}(S) (abelian のgenerate) ✓
- C_{O_p(G)}(P) ⊆ P ⇒ C_T(L_{2n+1}(T)) ⊆ L_{2n+1}(T) (Lem B.1(f)) ✓
- O_{p'}(G) = 1 (assumption) ✓
⇒ X ⊆ O_p(G) = T

## Thm B.4 (Puig '76) — 4 Step 詳解

### Statement (2 部)

```
Assume: p odd, G solvable odd, S ∈ Syl_p(G)

(a) G = O_{p'}(G)·N_G(Z(L(S)))    [factorization]
(b) O_{p'}(G)=1 ⇒ Z(L(S)) ⊲ G     [normality]
```

### Key observation: Thm 6.2 との同値性

**BG Thm 6.2** (Isaacs Thm 7.6 odd-order spec):
```
G solvable odd, p odd, S ∈ Syl_p(G)
⇒ Z(J(S))·O_{p'}(G) ⊲ G
```

**App.B Remark** (L4691): 「Theorem B.4(a) serves as a substitute for Theorem 6.2」.

**形式化上の等価性**:
- Odd solvable では J(S) = L(S) (Lem B.1(e)-(f) + J の maximal abelian characterization より)
- ⇒ Z(J(S)) = Z(L(S))
- ⇒ Thm 6.2 ≡ Thm B.4 (odd solvable 下)

---

### Step 1: (b) ⇒ (a) の Frattini argument

```
Assume O_{p'}(G) = 1 ⇒ Z(L(S)) ⊲ G  [assume (b)]
Show: G = O_{p'}(G)·N_G(Z(L(S)))  [conclude (a)]
```

**手順**:
1. Bar G := G/O_{p'}(G), Bar S := S·O_{p'}(G)/O_{p'}(G) とする
2. Bar G で O_{p'}(Bar G) = 1 (quotient char)
3. Bar S ∈ Syl_p(Bar G) ⇒ (b) より Z(L(Bar S)) ⊲ Bar G
4. Bar Z := Z(L(Bar S)) とすると Z(L(S))·O_{p'}(G) ⊲ G
5. Z(L(S)) は Sylow p-sub of Z(L(S))·O_{p'}(G)
6. **Frattini argument**: G = Z(L(S))·O_{p'}(G)·N_G(Z(L(S))) = O_{p'}(G)·N_G(Z(L(S)))

---

### Step 2: Z(L(S)) ⊆ Z(L(T)) (where T := O_p(G))

```
By Lem B.3: L_*(S) ⊆ L(T)
By Lem B.1(f): L(T) ⊇ C_S(L_*(S)) ⊇ Z(L(S))
⇒ Z(L(S)) ⊆ Z(L(T)) =: Y
```

**Key**: L_*(S) ⊆ L(T) で abelian containing hierarchy が collapsed → Z(L(S)) が smaller abelian として Y に subsumed.

---

### Step 3: L(S) normalizes a special group C ∩ S

```
Define: C/C_G(Y) := O_p(G/C_G(Y))  [Y := Z(L(T))]
Show: L(S) ⊲ N_G(C ∩ S)
```

**Proof** (by Thm A.5 再応用):
1. Y = Z(L(T)) ⊲ G (characteristic of T) ⇒ Y ⊲ S (Sylow)
2. Y abelian ⇒ Y ⊆ L_*(S) (Lem B.1(e))
3. L(S) = L_G(L_*(S)) (Lem B.1(g)) ⇒ Y → L(S)
4. **Thm A.5(1)** を X = L(S), P = Y で: LC_G(Y)/C_G(Y) ⊆ O_p(G/C_G(Y)) = C/C_G(Y)
5. ⇒ L ⊆ C ⇒ L ⊆ C ∩ S
6. **Lem B.2**: L(C ∩ S) = L(S) (∵ L(S) ⊆ C ∩ S ⊆ C and C ⊇ L(S) ⇒ L(C) = L(S))
7. ⇒ L(S) ⊲ N_G(C ∩ S)

---

### Step 4: 最終結論 (Z(L(S)) ⊲ G)

```
C ∩ S is Sylow p of C
(C ∩ S)C_G(Y)/C_G(Y) = Sylow p of C/C_G(Y) = entire C/C_G(Y)  [C/C_G(Y) p-group]
⇒ C = C_G(Y)·(C ∩ S)
Frattini: G = C·N_G(C ∩ S) = C_G(Y)·N_G(C ∩ S)

Step 2: Z(L(S)) ⊆ Z(C_G(Y))  [smaller abelian]
Step 3: Z(L(S)) ⊲ N_G(C ∩ S)  [by L(S) ⊲ N_G(C ∩ S)]
⇒ Z(L(S)) ⊲ G
```
