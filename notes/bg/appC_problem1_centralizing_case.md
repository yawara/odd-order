# BG App.C Problem 1 — 中心化作用の場合は全ての奇素数 q で不可能 (人手証明)

2026-08-10。[issue 0180](../../issues/0180-bg-appc-problem1-p-eq-three.md)。
ChatGPT Work の `q = 3` 計算 ([`appC_problem1_chatgpt_answer.md`](appC_problem1_chatgpt_answer.md)) を
再現・検証したあと、その普遍完備化のアイデアを分解して得た**計算機を使わない証明**。

⚠ これは未解決問題 (Péterfalvi 1993) の**部分解決**であって、全面解決ではない。
未解決のまま残るのは「`g` が `σ(U)` を非自明に (位数 3 で) 作用させる場合」。

## 定理

`p = 3`, `q` を奇素数、`F = GF(3^q)`、`S ⊆ F^×` を平方元全体 (= ノルム 1 の元全体、
`|S| = (3^q−1)/2`)、`P = (F,+)`、`U = S` が乗法で `P` に作用して `H = P ⋊ U`、
`P₀ = F₃ ≤ P` とする。

> **Glauberman–Norton Prop 9 の仮説 (B) は、`σ(P₀)^y` が `σ(U)` を中心化する場合には
> どんな (有限とは限らない) `G` でも成立しない。**

**系 1.** `3 ∤ φ((3^q−1)/2)` なる奇素数 `q` については (B) 自体が不可能。
(このとき `Aut U` に位数 3 の元が無いので、書籍 p.1094 の注により作用は自動的に中心化。)
実測 (GAP, `q ≤ 43`) では

| `q` | 3 ∤ φ(n) ⟹ 本定理で決着 | 備考 |
|---|---|---|
| 3 | ✗ (`n = 13`, `φ = 12`) | 別途 計算機で決着済 |
| **5, 11, 17, 23, 37, 43** | ✅ **決着** | `q = 5`: `n = 121`; `q = 11`: `n = 23·3851` |
| 7, 13, 19, 29, 31, 41 | ✗ | `e ≠ 1` が残る (未解決) |

**系 2.** `q = 3` は `e ≠ 1` も含めて否定で確定 (計算機による;
[`verify_gn.g`](../meta/gap/verify_gn.g))。

## 記号

`σ` は省略して `H ≤ G` と書く。`x` = `P₀` の生成元 = `1 ∈ F` に対応する平行移動 (位数 3)。
`y ∈ Q`、`g := x^y`、`c := x^{-1}g = [x,y]`。`v ∈ V` に対し `v^{g^i} := g^{-i} v g^i`。

`U` の共役作用による `x` の軌道は、`P = F` と同一視すると **`S` そのもの** になる
(`x^{u^k}` = `θ^{∓k}` による平行移動、`θ` = `U` の生成元)。ここが Paley 集合が現れる理由。

## 補題 A (語の恒等式)

> 群の元 `x, g` が `x³ = g³ = 1` を満たすとき、`c := x^{-1}g` について `[c, c^x] = (gx)³`。

証明: `c^x = x^{-1}(x^{-1}g)x = x^{-2}gx = xgx` (`x^{-2} = x`)。よって
`[c,c^x] = c^{-1}(c^x)^{-1}c(c^x) = (g^{-1}x)(x²g^{-1}x²)(x²g)(xgx) = g^{-2}·xgxgx = (gx)³`
(`g^{-2} = g`, `x³ = 1` を使った)。∎

⟹ `Q` が可換で `x` が `Q` を正規化するので `c, c^x ∈ Q` は可換、つまり **`(gx)³ = 1`**。
(**これが (B) から取り出せる唯一の非自明な関係式**であり、以下すべての出発点。)

## 補題 B (Paley 型の張り生成)

> `q` を奇素数とし `Q₀ := 3^q`。`T := { s ∈ F : s ∈ S かつ s+1 ∈ S }` とおくと
> `|T| = (Q₀−3)/4` であり、**`T` は `F` を `F₃` 上張る**。

個数: `χ` を平方剰余指標として
`|T| = ¼ Σ_{s≠0,−1}(1+χ(s))(1+χ(s+1)) = ¼[(Q₀−2) + 1 − 1 − 1] = (Q₀−3)/4`。
ここで `Σ_{s≠0,−1}χ(s(s+1)) = Σχ(1+1/s) = −1` (`s ↦ 1/s` の置換)、`χ(−1) = −1`
(`3^q ≡ 3 (mod 8)` ゆえ `4 ∤ 3^q−1`) を使った。

張ること: 超平面 `W = ker λ` (`λ: F → F₃` 非零線形) に `T ⊆ W` と仮定する。
`W` 上自明な加法指標 `ψ_0 = 1, ψ_1, ψ_2` を使って

```
|T ∩ W| = (1/12) Σ_{j=0}^{2} Σ_{s≠0,−1} (1+χ(s))(1+χ(s+1)) ψ_j(s)
```

`j = 0` の項は `|T|/3`。`j ≠ 0` の項は Gauss 和 `|Σχψ| = √Q₀` と Weil 評価
`|Σ_s χ(s(s+1))ψ(s)| ≤ 2√Q₀` (`deg f = 2` の相異根 2 個 + `deg g = 1` ⟹ 係数 `2+1−1`) から
各々 `(4√Q₀ + 6)/12` 以下。よって

```
|T ∩ W| ≤ |T|/3 + (2/3)√Q₀ + 1
```

`|T ∩ W| = |T|` と仮定すると `(2/3)|T| ≤ (2/3)√Q₀ + 1`、すなわち `Q₀ − 4√Q₀ − 9 ≤ 0`、
`√Q₀ ≤ 5.61`、`Q₀ ≤ 31`。`q ≥ 5` では `Q₀ ≥ 243` なので矛盾。
`q = 3` (`Q₀ = 27`) だけは直接確認: `|T| = 6` で `rank_{F₃} T = 3` (GAP,
[`verify_centralizing.g`](../meta/gap/verify_centralizing.g))。∎

⚠ `q = 1` では `T = ∅` で成り立たない (`|T| = (3−3)/4 = 0`)。`q` が素数なら `q ≥ 3` なので無害。

## 補題 C (交差交換子)

> `g³ = 1` とし、`s, t, s+t ∈ S` すべてについて `(g·s)³ = 1` が成り立つとする
> (`S ⊆ P` を平行移動の集合と見る)。このとき **`[t, s^g] = 1`**。

証明: `g³ = 1` より `(g·v)³ = v^{g²} v^{g} v` なので、仮定は `v^{g²}v^gv = 1` (`v = s, t, s+t`)。
`a_i := s^{g^i}`, `b_i := t^{g^i}` と書くと `(s+t)^{g^i} = a_i b_i` (共役は自己同型、`P` は可換) ゆえ

```
a₂a₁a₀ = 1,   b₂b₁b₀ = 1,   a₂b₂a₁b₁a₀b₀ = 1.
```

第 1・2 式から `a₂ = (a₁a₀)^{-1}`, `b₂ = (b₁b₀)^{-1}` を第 3 式に代入して
`a₁b₁a₀b₀ = (b₁b₀)(a₁a₀)`。`P` と `P^g` はそれぞれ可換なので `[a₁,b₁] = [a₀,b₀] = 1`。
左辺 `= b₁a₁a₀b₀`、右辺 `= b₁b₀a₁a₀` から `b₁` を消して `a₁a₀b₀ = b₀a₁a₀`、
すなわち `(a₁a₀)^{b₀} = a₁a₀`。`a₀^{b₀} = a₀` だから `a₁^{b₀} = a₁`、つまり `[a₁, b₀] = 1`。∎

## 定理の証明

(B) の witness `(G, σ, Q, y)` があり、`⟨g⟩ = σ(P₀)^y` が `σ(U)` を中心化するとする。

1. 補題 A より `(gx)³ = 1`。
2. `v ∈ σ(U)` で共役すると `(g^v x^v)³ = 1`。中心化の仮定より `g^v = g` なので
   **`(g·s)³ = 1` が全ての `s ∈ S` について成立**。
3. 補題 C を `t = x = 1 ∈ S` に適用: `s ∈ T` なら `s, t, s+t = s+1` が全て `S` に属するので
   `[x, s^g] = 1`。
4. `C := { v ∈ P : [x, v^g] = 1 }` は `P` の部分群で `T ⊆ C`。補題 B より `C = P`。
   特に **`[x, x^g] = 1`**、`g` で共役して `[x^g, x^{g²}] = 1`。
5. `c³ = (x^{-1}g)³ = (x^g x^{g²} x)^{-1}` (`g³ = 1` から直接計算)。手順 4 と手順 1
   (`x^{g²}x^gx = 1`) より `x^gx^{g²}x = x^{g²}x^gx = 1`、よって **`c³ = 1`**。
6. `c = [x,y] ∈ Q` で `Q` は 3′-群だから `c = 1`、すなわち `g = x`。
   しかし `⟨g⟩ = σ(P₀)^y` は `σ(U)` を正規化する一方、`x` は `σ(U)` を正規化しない
   (`H` は Frobenius で `N_H(U) = U`、`x ∈ σ(P)∖1`; これは `σ(H)` の内部で決まるので
   `G` を大きくしても変わらない)。矛盾。∎

**`G` の有限性は使っていない。** また合同枚挙も有限表示も使っていない
(ChatGPT の普遍完備化 `Γ_e` は発見の道具としては本質的だったが、証明には現れない)。

## 一般化 (`e ≠ 1` へ向けて)

手順 2 でしか中心化を使っていない。よって同じ証明がそのまま次を与える:

> `S₀ := C_{σ(U)}(g)` を `F^×` の部分群と見て、`T₀ := { s ∈ S₀ : s+1 ∈ S₀ }` が
> `F` を `F₃` 上張るならば、(B) は不可能。

`e ≠ 1` のとき `|S₀| = gcd(e−1, n)`。`q = 3`, `e ∈ {3,9}` では `gcd(2,13) = gcd(8,13) = 1` で
`S₀ = 1` となり、この一般化は効かない (実際 `q = 3` の `e ≠ 1` は計算機で潰した)。
`|S₀|` が `≳ Q₀^{3/4}` あれば同じ指標和評価で `T₀` の張りが従うはず (未検証)。

## 残っている未解決部分

`3 | φ((3^q−1)/2)` となる奇素数 `q` (例 `q = 3, 7, 13, …`) の**非中心化作用** `e ≠ 1`。
`q = 3` は計算機で決着済。`q = 7` は ChatGPT が「`e = 151, 941` も不可能」と主張しているが
**未検証** (根拠の「index 3 ⟹ `H ◁ Γ`」が示されていない)。
