# BG App.C Problem 1 (Péterfalvi 1993) — 部分解決

[issue 0180](../../issues/0180-bg-appc-problem1-p-eq-three.md)。2026-08-10 開始、2026-08-11 更新。
⚠ **全面解決ではない** — 決着したのは `q ≤ 29` と、全 `q` での可解/有限奇位数の場合。

## 現状サマリ (2026-08-11)

`p = 3`、`q` は奇素数、`F = GF(3^q)`、`n = (3^q−1)/2`、`U ⊆ F^×` = 平方元 (= ノルム 1) 全体、
`P = (F,+)`、`H = P ⋊ U`、`P₀ = F₃`。witness `(G, σ, Q, y)` に対し `x` = `σ(P₀)` の生成元、
`g = x^y`、`c = x^{-1}g = [x,y] ∈ Q`。`g` は `σ(U)` を `u ↦ u^e` で正規化 (`e³ ≡ 1 mod n`)。
**`G` の有限性はどこでも使わない** (有限性が要るのは `Q` と各層だけ)。

| 場合 | 状態 | 手段 |
|---|---|---|
| **`e ∈ ⟨3⟩`** (`g` の作用が Frobenius 冪) | ✅ **どんな `G` でも不可能** | **定理 1** (計算機不要、Lean 化済) |
| ⟹ `3 ∤ φ(n)` なる `q` = 3, 5, 11, 17, 23, 37, 43, … | ✅ **完全決着** | 定理 1 (`e = 1` が強制される) |
| **`e ∉ ⟨3⟩`** かつ `G` 可解 (有限奇位数を含む) | ✅ **完全決着** | **定理 2** (Lean 化済) + 奇数位数定理 |
| **`q = 7, 13, 19, 29`** (exotic 指数すべて) | ✅ **完全決着** | **collision-span 判定法** (Lean 化済) + GAP 証明書 |
| `q = 31, 41, …` で `e ∉ ⟨3⟩`、`G` 非可解 | ❌ **未解決** | 判定法は使えるが証明書の計算が重い / 一般証明が無い |

⟹ **`q ≤ 29` の全ての奇素数で hypothesis (B) は不可能**。さらに全ての `q` について、
witness の `G` は非可解でなければならない (定理 2)。

**3 つの道具** (すべて Lean で機械検証済、axiom-clean):

1. **定理 1** — `e` が Frobenius 冪なら矛盾。鍵は Paley 集合 `T = {s : s, s+1 ∈ U}` が `F` を張ること
   (`T ∩ (−T) = ∅` から出る初等証明、Weil 不要)。
2. **定理 2** — `e` が Frobenius 冪でないなら `N = ⟨σ(P), σ(P)^g⟩` は非自明な完全群
   (補題 D: 関係格子 `L_e = F³`)。⟹ `G` は非可解。
3. **collision-span 判定法** — `D(p) = p^e−(p−1)^e` の**衝突**から作る `S` たちが `F` を張れば
   witness は存在しない。`q` ごとに `S` の階数を測れば決着する (証明書は GAP)。

**残る一般化**: 「すべての exotic `e` で `S` たちが `F` を張る」。壁は
**`z ↦ z^E` (乗法群の位数 3 の自己同型) の擬ランダム性**に一本化されている (下記「なぜ難しいのか」)。

## 共通の出発点

### 補題 A (語の恒等式)

> `x³ = g³ = 1` のとき、`c := x^{-1}g` について `[c, c^x] = (gx)³`。

証明: `c^x = x^{-1}(x^{-1}g)x = x^{-2}gx = xgx` (`x^{-2} = x`)。よって
`[c,c^x] = (g^{-1}x)(x²g^{-1}x²)(x²g)(xgx) = g^{-2}·xgxgx = (gx)³`。∎

`Q` は可換で `x` が `Q` を正規化するので `c, c^x ∈ Q` は可換 ⟹ **`(gx)³ = 1`**。
これが (B) から取り出せる唯一の非自明な関係式で、以下すべての出発点。

### 補題 A′ (`U`-共役)

`(gx)³ = 1` ⟺ `x^{g²}x^gx = 1`。これを `v ∈ σ(U)` で共役する。`gv = v^e g` より
`(x^g)^v = (x^{v^e})^g`、`(x^{g²})^v = (x^{v^{e²}})^{g²}` なので、`s := x^v` (これは `S` 全体を走る) として

```
R(s):   (s^{e²})^{g²} · (s^e)^g · s = 1        (s ∈ S)
```

ここで `s^e` は **`F^×` の中の冪**、`(·)^{g^i}` は共役。`e = 1` なら `s^{g²}s^gs = 1`。

## 定理 1 (`e ∈ ⟨3⟩` — 計算機不要)

> `e` が Frobenius の冪 `3^j` ならば (B) は成立しない (`G` は有限でなくてよい)。

`⟨3⟩ ≤ (Z/n)^×` の位数は `q` (∵ `n ∣ 3^q−1`)。よって `e³ = 1` かつ `e ∈ ⟨3⟩` は
**`e = 1` (全ての `q`)** または **`q = 3` の `e = 3, 9`** に限る。

### 補題 B (Paley 型の張り生成) — **初等証明・Lean 化済** (2026-08-10)

> `T := { s ∈ F : s ∈ S かつ s+1 ∈ S }` は `F` を `F₃` 上張る (`q` は奇素数)。

Lean: [`OddOrder/Algebra/PaleySpanning.lean`](../../OddOrder/Algebra/PaleySpanning.lean)
`OddOrder.Paley.addClosure_paleySet_eq_top` (AxiomsCheck 登録済)。
仮説は **標数 3・`|F| ≡ 3 (mod 4)`・`|F| > 9`** の 3 つだけ。

**(B1) 十分多い.** `u² ≠ 1` なる単数 `u` について、標数 3 では

```
(u − u⁻¹)² + 1 = (u + u⁻¹)²      (両辺 = u² + u⁻² − 1)
```

なので `s := (u − u⁻¹)²` は平方元で `s + 1` も平方元。`s ≠ 0` は `u² ≠ 1` から、
`s + 1 ≠ 0` は `u² ≠ −1`、すなわち **`−1` が非平方** (`Q ≡ 3 mod 4` ⟸ `q` 奇) から出る。
⟹ `u ↦ (u − u⁻¹)²` は `{u : u² ≠ 1}` (`Q − 3` 個) を `T` に写す。ファイバーは
`u − u⁻¹` が `u` を反転を除いて決め、平方が符号を足すので `{u, −u, u⁻¹, −u⁻¹}` の高々 4 点:
`(u−u⁻¹)² = (w−w⁻¹)²` を `u²w²` 倍して因数分解すると `(u−w)(uw+1)·(u+w)(uw−1) = 0`。

```
4 |T| ≥ Q − 3          (実際は等号: |T| = (Q−3)/4)
```

**(B2) 非対称.** `−1` が非平方なので `s ∈ T` なら `−s` は平方元ですらない ⟹ **`T ∩ (−T) = ∅`**。
`W := ⟨T⟩` (加法) は `T ∪ (−T)` を含むので `|W| ≥ 2|T|`。

**(B3) 結論.** `F` の位数は 3 冪なので真の加法部分群の指数は 3 で割れ、`W ≠ F` なら
`3|W| ≤ Q`。(B1)(B2) と合わせて `6|T| ≤ Q ≤ 4|T| + 3` ⟹ `|T| ≤ 1` ⟹ `Q ≤ 7`。
`Q ≥ 27` に矛盾。よって **`W = F`**。∎

⚠ **`q = 3` も同じ証明で通る** (`Q = 27`: `2|T| = 12 > 9 = 3^{q−1}`)。以前の
「次元下界 + 正規基底定理 + `ker Tr` 除去」経路は `q = 3` で自明成分が `ker Tr` に落ちて
破綻していた (`Tr(1) = 3 = 0`) が、この経路は**場合分けなし**。

⟹ **定理 1 から解析的入力 (Weil 評価) が完全に消えた**。旧証明 2 種は独立な別証明として
下記に残す。

### 補題 C (交差交換子の消去)

> `g³ = 1` とし、`s, t, s+t ∈ S` について `R` が「同じ層構造」で書けるとする。すなわち
> `a_i, b_i` (`i = 0,1,2`, `a_i, b_i ∈ P^{g^i}`) が `a₂a₁a₀ = 1`, `b₂b₁b₀ = 1`,
> `(a₂b₂)(a₁b₁)(a₀b₀) = 1` を満たすとする。このとき **`[a₁, b₀] = 1`**。

証明: 第 1・2 式から `a₂ = (a₁a₀)^{-1}`, `b₂ = (b₁b₀)^{-1}` を第 3 式に入れて
`a₁b₁a₀b₀ = (b₁b₀)(a₁a₀)`。`P` と `P^g` はそれぞれ可換なので `[a₁,b₁] = [a₀,b₀] = 1`。
左辺 `= b₁a₁a₀b₀`、右辺 `= b₁b₀a₁a₀` から `b₁` を消して `(a₁a₀)^{b₀} = a₁a₀`、
`a₀^{b₀} = a₀` より `[a₁, b₀] = 1`。∎

### 定理 1 の証明

`e = 3^j` なら `σ_e : s ↦ s^e` は **`F₃`-線形な全単射** (Frobenius の冪)。よって `R(s)` は
`a₀ = s`, `a₁ = (σ_e(s))^g`, `a₂ = (σ_e²(s))^{g²}` として `a₂a₁a₀ = 1` の形で、しかも
`s + t` に対する `R(s+t)` の各層は `a_ib_i` になる (`σ_e` の加法性)。⟹ 補題 C が使えて

* `s, t, s+t ∈ S` ⟹ `[(σ_e(s))^g, t] = 1`
* `t = x = 1` と取ると `s ∈ T` について `[(σ_e(s))^g, x] = 1`
* `σ_e` は線形全単射なので `σ_e(T)` も `F` を張る (補題 B) ⟹ `[v^g, x] = 1` (∀`v ∈ P`)
* 特に **`[x, x^g] = 1`**、`g` で共役して `[x^g, x^{g²}] = 1`
* `c³ = (x^gx^{g²}x)^{-1}` (直接計算)。`R(x)` = `x^{g²}x^gx = 1` (∵ `1^e = 1`) と合わせて
  `x^gx^{g²}x = x^{g²}x^gx = 1` ⟹ **`c³ = 1`**
* `c ∈ Q` は 3′-元ゆえ `c = 1`、`g = x`。しかし `⟨g⟩ = σ(P₀)^y` は `σ(U)` を正規化し、
  `x` は正規化しない (`H` は Frobenius, `N_H(U) = U`; これは `σ(H)` の内部で決まるので
  `G` を大きくしても変わらない)。矛盾。∎

**`G` の有限性も、合同枚挙も、有限表示も使っていない。**

## 定理 2 (`e ∉ ⟨3⟩` — 完全群が現れる)

`e ∉ ⟨3⟩` だと `σ_e` は加法的でないので補題 C が使えない。代わりにアーベル化を測る。

**関係格子**を `L_e := span_{F₃} { (s, s^e, s^{e²}) : s ∈ S } ≤ V ⊕ V ⊕ V` (`V = F`, `dim = q`) と置く。

> **定理 2.** `L_e = V³` ならば、任意の witness において
> `N := ⟨σ(P), σ(P)^g, σ(P)^{g²}⟩` は**非自明な完全群** (`N = [N,N] ≠ 1`)。
> 特に `G` は可解でなく、**有限奇位数群は witness になれない** (奇数位数定理より可解だから)。

証明: `N` のアーベル化で `π_i(v) :=` (`v^{g^i}` の像) と置くと各 `π_i : V → N^{ab}` は準同型。
`R(s)` は `π₀(s) + π₁(s^e) + π₂(s^{e²}) = 0`。`Φ(a,b,c) := π₀(a)+π₁(b)+π₂(c)` は `F₃`-線形で
`{(s,s^e,s^{e²}) : s ∈ S}` を消すから `L_e` を消す。`L_e = V³` なら `Φ ≡ 0`、すなわち
`π₀ = π₁ = π₂ = 0`、つまり `σ(P), σ(P)^g, σ(P)^{g²} ⊆ [N,N]`。この 3 つが `N` を生成するので
`N = [N,N]`。`σ` は単射なので `σ(P) ≠ 1`、ゆえに `N ≠ 1`。∎

### 補題 D — `L_e = V³ ⟺ e ∉ ⟨3⟩` (一般 `q` で証明済)

実測は上表のとおりだが、**これは指標和を使わずに完全に証明できる**。

> **補題 D.** `q` を奇素数、`Q = 3^q`、`n = (Q−1)/2`、`e ∈ (Z/n)^×` を `e³ = 1` とする。
> このとき `L_e = V³` ⟺ `e ∉ ⟨3⟩ ≤ (Z/n)^×`。

証明。`n` は奇数 (`Q − 1 ≡ 2 mod 4`) なので、CRT で `ẽ ≡ e (mod n)`, `ẽ ≡ 1 (mod 2)` を取れば
`gcd(ẽ, Q−1) = 1` かつ `ẽ³ ≡ 1 (mod Q−1)`、しかも `s ∈ S` について `s^{ẽ} = s^e`。

`L_e ≠ V³` ⟺ ある `(λ,μ,ν) ≠ 0` で `Tr(λs + μs^{ẽ} + νs^{ẽ²}) = 0` (∀`s ∈ S`)。
`ẽ` は奇数なので `a = −s` (`a ∉ S`) でも `a^{ẽ} = −s^{ẽ}` となり、この条件は
**`F^×` 全体での消滅**と同値。`a = 0` でも消えるので、多項式関数

```
f(a) = Tr(λa) + Tr(μ a^{ẽ}) + Tr(ν a^{ẽ²}) = Σ_j λ^{3^j} a^{3^j} + Σ_j μ^{3^j} a^{ẽ·3^j} + Σ_j ν^{3^j} a^{ẽ²·3^j}
```

が `F` 上恒等的に 0 ⟺ `a^Q − a` で簡約した多項式が 0。指数は `Z/(Q−1)` の中で
`A := ⟨3⟩`, `ẽA`, `ẽ²A` に属する (`3^q ≡ 1 mod Q−1` ゆえ `|A| = q`)。これらは `A` の剰余類なので
**一致するか交わらないかのいずれか**で、`ẽ² = ẽ^{-1}` だから

* `ẽ ∈ A` なら 3 つとも `A` に一致 (打ち消し合いが起きる。実際 `λ^{3^j}+μ^{3^{j−k}}+ν^{3^{j−2k}} = 0`
  という `q` 本の方程式になり解空間は `2q` 次元 ⟹ `dim L_e = 3q − 2q = q`、実測と一致)
* `ẽ ∉ A` なら 3 つは互いに素。各集合内でも指数 `3^j` は相異なるので、全係数が 0、すなわち
  `λ^{3^j} = μ^{3^j} = ν^{3^j} = 0`、つまり `λ = μ = ν = 0`。⟹ `L_e = V³`。

最後に `ẽ ∈ ⟨3⟩ (mod Q−1)` ⟺ `e ∈ ⟨3⟩ (mod n)` (`3^j` も `ẽ` も奇数なので CRT で一意)。∎

⟹ **定理 2 は全ての奇素数 `q` と全ての `e ∉ ⟨3⟩` について無条件に成立する。**

## 主定理 (定理 1 + 定理 2 + 補題 D)

> `p = 3`、`q` を任意の奇素数とする。Glauberman–Norton Prop 9 の仮説 (B) を満たす群 `G` は
> **非自明な完全部分群を含む**。特に **`G` は可解でない**。
> ⟹ 奇数位数定理より、**有限奇位数群は (B) を満たさない**。

`e ∈ ⟨3⟩` なら定理 1 で `G` の存在自体が否定され、`e ∉ ⟨3⟩` なら補題 D + 定理 2 で
`N = ⟨σ(P), σ(P)^g, σ(P)^{g²}⟩` が非自明完全群になる。∎

## `q = 7` の完全決着

万能完備化 `Γ_e = ⟨H, z | [z,z^x]=1, (xz)³=1, (xz)u(xz)^{-1}=u^e⟩` で `H̄ := ⟨P,u⟩` の指数を測ると
**`[Γ_e : H̄] = 3`** (GAP の Todd–Coxeter、`e = 151`)。ここから:

1. `|H̄|` は `H` の準同型像ゆえ**奇数**。指数 3 の作用で `Γ_e/core ↪ S₃`、`[H̄:core] ∈ {1,2}` だが
   奇数なので `core = H̄`、すなわち **`H̄ ◁ Γ_e`**。
   (⚠ ChatGPT はここを「埋め込みがあれば `H ◁ Γ`」と書いただけで根拠を示していなかった。)
2. `P̄ = O₃(H̄)` は `H̄` の特性部分群 ⟹ `P̄ ◁ Γ_e` ⟹ `P̄^g = P̄` ⟹ `N = P̄` は**可換**。
3. 定理 2 の議論 (`L_e = V³`) より `P̄ = [P̄,P̄] = 1`。
4. ⟹ `P` は `Γ_e` に埋まらない ⟹ **witness 無し**。∎

⚠ `Γ_e` の位数そのものは自明部分群上の合同枚挙が 12 GB でも溢れて未確定 (指数 3 の枚挙は完走)。
上の論法は位数を要しない。

## 残っている未解決部分

**`q ≥ 13` で `3 | φ((3^q−1)/2)` かつ `e ∉ ⟨3⟩`、かつ `G` が非可解 (無限を含む)**。
そこでは定理 2 により `N = ⟨P, P^g, P^{g²}⟩` は「3 個の共役な `C₃^q` で生成される完全群」で、
`U` (位数 `n`, `P` に既約かつ不動点なく作用) が正規化している。次の一手の候補:

1. 定理 2 の完全群 `N` をさらに潰す。`N` は 3 個の共役可換 3-部分群で生成され、`U`-作用をもつ。
   `q = 7` では実際に潰れる (下記) ので、その論法を一般化するのが本線。

## ✅ q = 13 決着 — collision-span 障害 (2026-08-11)

**ChatGPT Work (5.6 Sol ウルトラ, 63分) が出し、こちらで論証を全ステップ検証・計算を独立再現した。**
`q = 7` の合同枚挙に代わる**一般の判定法**で、`q = 13` (最小の未決ケース) が落ちた。

### 判定法 (一般、証明済)

`a(t) ∈ A = σ(P)`, `b(t) = a(t)^g ∈ B`, `d(t) = a(t)^{g²}` と置く (`E` = `e` の奇数持ち上げ)。

1. 関係式 `d(t^{E²}) b(t^E) a(t) = 1` に `t = r^E` を入れて
   **`d(r) = a(−r^E) b(−r^{E²})`**、逆元を取って `d(−r) = b(r^{E²}) a(r^E)` (`r ∈ U`)。
   ⚠ `−r ∉ U` なので「`r → −r` を代入」はできない。逆元経由が正しい。
2. `T := {p ∈ U : p−1 ∈ U}`、`K(p) := (p−1)^{E²} − p^{E²}`、`D(p) := p^E − (p−1)^E` と置くと、
   `d` の加法性 (`z = pz + (−(p−1)z)`) から `p ∈ T`, `z ∈ U` について
   **`d(z) = a(−p^E z^E) · b(K(p) z^{E²}) · a((p−1)^E z^E)`**。
3. **衝突** `D(p) = D(r)` (`p ≠ r ∈ T`) があると、`δ := r^E − p^E` として 2 の両表示を突き合わせ
   **`b(K(r) z^{E²}) = b(K(p) z^{E²})^{a(−δ z^E)}`**。
4. さらに `δ ∈ U` なら `z := (δ⁻¹)^{E²}` と選ぶと `δ z^E = 1` となり
   **`b(S(p,r))^{a(−1)} = b(T(p,r))`**、ただし `S(p,r) = K(p)·δ^{−E}`。

> **collision-span 判定法**: 衝突たちから来る `S(p,r)` が `F` を `F₃` 上張れば witness は存在しない。

理由: `b(S)` たちが `B` を生成するので `B^{a(−1)} ≤ B`、`B` は有限ゆえ等号 ⟹ `a(−1) ∈ N_G(B)`。
`U` で共役すると `a(−u⁻¹) ∈ N_G(B)` (∀`u ∈ U`) で、`−U` は `F` を張るから **`A ≤ N_G(B)`**。
すると `AB` は部分群で `N = ⟨A,B⟩ = AB` は**有限 3-群** ⟹ 冪零 ⟹ 完全なら自明。
定理 2 (`N` は非自明な完全群) に矛盾。**`G` の有限性はどこにも使わない。**

## 旧: Itô の定理経由の攻め筋 (2026-08-11 午前)

**残る未解決ケース (`q ≥ 13`, `e ∉ ⟨3⟩`) を「有限体の被覆補題」1 本に還元できた。**

### 骨子

`A := σ(P)`, `B := σ(P)^g` と置く (どちらも位数 `3^q` の初等アーベル群)。既に証明済:

* `N = ⟨A, B⟩` (第 3 層は不要、`layerClosure_eq_closure_two`)
* `e ∉ ⟨3⟩` なら `N` は非自明な完全群 (定理 2)

ここで **Itô の定理** (1955, 任意群で成立): *`G = AB` (`A`, `B` 可換部分群) なら `G` はメタアーベル*。
⟹ **`BA ⊆ AB` が示せれば `N = AB` がメタアーベル = 可解、しかし `N` は完全かつ非自明で矛盾**。
⟹ witness は存在しない = 残るケースが決着する。

### 関係式から出る「直接書き換え」

`α, β, γ` を 3 層のパラメータ表示とすると、関係式 `R(v)` は `s ∈ U` について
`γ(s) = α(s^e)⁻¹ β(s^{e²})⁻¹`。`γ` が加法的であること (`γ(s+t) = γ(s)γ(t)`) を使って整理すると:

```
s, t, s+t ∈ U  ⟹  β(−s^{e²}) · α(−t^e) = α(s^e − (s+t)^e) · β(t^{e²} − (s+t)^{e²})
```

すなわち **`(b, a) = (−s^{e²}, −t^e)` の形のペアは直接 `AB` に落ちる** (直接良ペア `D`)。

### 被覆補題 (実測済・一般証明が残件)

> **(I)** `−b ∈ U` なる任意の `b` と任意の `a` に対し、`a = a₁ + a₂` を
> `(b, a₁) ∈ D` かつ `(B₁(b,a₁), a₂) ∈ D` となるように取れる。

(I) があれば `β(b)α(a) = α(A₁)β(B₁)α(a₂) = α(A₁)α(A₂)β(B₂) ∈ AB`。
一般の `b` は `−b ∈ U + U` (平方元の和は全体を覆う) から 2 つに分けて (I) を 2 回使えばよい。
⟹ `BA ⊆ AB`。

### 一般証明の見通し

指数を**奇数代表**に取ると (補題 D で既にやっている) 平方剰余指標 `χ` について
`χ(z^e) = χ(z)^e = χ(z)` となるので、条件が大幅に簡約される。実際、第 1 段の条件は
`r := s/t` と置くと

```
r ∈ U,  1 + r ∈ U,  (1+r)^{e²} − 1 ∈ U
```

に帰着する (最初の 2 つは Paley 集合 `T` そのもので `|T| = (Q−3)/4` と既知)。
残るのは 3 つ目の条件との連立で、発見的には密度 `1/32` (実測の平均試行数 30 と一致)。
⚠ 素朴な Weil 評価は指数 `e` が `n` 級で使えないので、要になるのは指標和

```
Σ_z χ((z−1)(z^e−1))     (χ = 平方剰余指標)
```

の非自明評価。乗法的 Fourier 展開すると `(Q−1)·Σ_φ c_{φ^{−e}} c_φ` (`c_φ` は正規化 Jacobi 和) に
なり、素朴には自明評価しか出ない。**ここが一般証明の唯一の穴**で、実測はどの `q`・どの `e` でも
きれいに `1/8` を出す (= `z ↦ z^e` は平方剰余指標に対して「ランダム」に振る舞う)。
⟹ 一般 `q` の証明にはこの型の指標和評価 (あるいは別経路) が要る。1993 年以来未解決なのも
おそらくここ。

## 🔍 なぜ一般 `q` が難しいのか (2026-08-11 の分析)

**2 つの攻め筋 (collision-span と Itô) は同じ壁に当たる**: 指数 `E` (乗法的位数 3、Frobenius 冪でない)
の冪写像 `z ↦ z^E` が、**平方剰余指標および加法構造に対して「ランダム」に振る舞う**ことの証明。

### collision-span 側

`T = {(u+u⁻¹)² : u² ≠ 1}` のパラメータ表示を使うと、`a = −(t+t⁻¹)`, `b = t − t⁻¹` (`t ∈ F^×`) で
`p = a²`, `p−1 = b²` (`a² − b² = 1`) となり

```
D_E(p) = a^{2E} − b^{2E} = (t+t⁻¹)^{2E} − (t−t⁻¹)^{2E} =: f(t)
```

`f(t⁻¹) = f(t)`、`f(−t) = f(t)`、`f(t³) = f(t)³` はいずれも `p` を変えないので**自明な対称性**であり、
**衝突は「偶然の一致」しか無い**。衝突数の期待値 `|T|²/Q ≈ Q/16` は誕生日則そのもので、
これを証明するには `D_E` のファイバーの均等分布 = 指標和評価が要る。
⚠ 単純な数え上げでは出ない: `D_E` が単射でも `Σ|fiber|² = |T|` は Cauchy–Schwarz の下界
`|T|²/Q = Q/16 < Q/4 = |T|` を満たしてしまう。

### Itô 側

被覆補題の核心は `Z = {z : z, z−1, z^E−1 がすべて平方元} ≠ ∅` で、要は

```
Σ_z χ((z−1)(z^E−1))      (χ = 平方剰余指標)
```

の非自明評価。乗法的 Fourier 展開すると正規化 Jacobi 和の相関 `Σ_φ c_{φ^{−E}} c_φ` になり、
素朴には自明評価しか出ない。指数 `E` は `n` 級なので Weil 評価も使えない。

### ⟹ 探すべき文献

「乗法的位数が小さい指数の Weil 和」「Niho 型指数」「planar function」周辺。`E³ = 1` という
強い条件 (`z ↦ z^E` が乗法群の位数 3 の自己同型) を使う評価があれば、両方の筋が同時に閉じる。
