```lean
private theorem thm34_aux : ∀ (n : ℕ)
    {F : Type*} [Field F] [IsAlgClosed F]
    {G : Type*} [Group G] [Finite G] [IsSolvable G]
    {V : Type*} [AddCommGroup V] [Module F V] [FiniteDimensional F V]
    (ρ : Representation F G V) (K R : Subgroup G) [K.Normal],
    Subgroup.IsComplement' K R →
    Nat.Coprime (Nat.card ↥K) (Nat.card ↥R) →           -- Hall (R 素数位数ゆえ |R|∤|K|)
    (∃ p : ℕ, p.Prime ∧ Nat.card ↥R = p) →
    Odd (Nat.card G) →
    (Nat.card G : F) ≠ 0 →                               -- char ∤ |G|
    (∀ v : V, (∀ r : ↥R, ρ (r : G) v = v) → v = 0) →    -- C_V(R) = 0 (S03b idiom)
    Nat.card G = n →
    ∀ g ∈ ⁅R, K⁆, ρ g = 1                               -- [R,K] ⊆ C_K(V)
-- main: `thm34_algClosed` は同型を hyp 引数で取り `thm34_aux (Nat.card G) ρ K R … rfl` を呼ぶ
```

設計判断:
- **alg-closed core** (Option A, GAP 2 決定): core を `[IsAlgClosed F]` で証明 (Thm 2.5/Gor 3.2.2 が必須)。
  一般 `F` は base change (BG (2.9) = `BaseChange.lean`) の別 leaf `thm34` で導く (downstream Thm 3.6 が消費)。
  induction は alg-closed F を保つ (subgroup HR も quotient G/N も同じ F)。
- **measure = `Nat.card G`** (= |G|), `Nat.strong_induction_on` (template = `frobeniusKernelIsNilpotent_aux`,
  `S03c_Thm37.lean:595`)。
- **Hall = `Coprime |K| |R|`** で表現 (Hall 構造体を持たず coprime で十分; 証明で使うのは coprime action)。
- **C_V(R)=0** / **C_K(V)**: S03b の idiom (`∀ v, (∀ r, ρ r v = v) → v=0` / `∀ g∈⁅R,K⁆, ρ g=1`)。
- minimal counterexample = `by_contra` で `[R,K]⊄C` (= `∃ g∈⁅R,K⁆, ρ g≠1`) を取り、IH で各 step → False。
