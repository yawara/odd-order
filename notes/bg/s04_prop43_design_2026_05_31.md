## statement (忠実, 弱めない)

p 奇素数, R p-群, [cl(R)≤2 ∨ (p>3 ∧ cl(R)≤3)]。φ(x)=xᵖ。⇒ (a) Ω₁(R) exp 1/p; (b) R'⊆Ω₁(R) ⇒ φ 準同型。

仮定は **packaged-commutator 形**を採る (precursor が全てこの形, nilpotencyClass→packaged bridge が repo 不在):
- `hcl : commutator R ≤ center R ∨ (3 < p ∧ ∀ a b c : R, ⁅⁅a,b⁆,c⁆ ∈ center R)`
- 署名分割: `omega1_pow_eq_one` (a: g∈Ω₁ ⇒ gᵖ=1) と `pow_mul_eq_mul_pow_of_commutator_le_omega1` (b: R'≤Ω₁ ⇒ (xy)ᵖ=xᵖyᵖ, **bare eq** 形; φ は非可換で MonoidHom でないので mk' で包まない)。

## 着地順 (anti-scaffold): (b) cl≤2 → (4.4) collection → (b) cl≤3 → (a)

### GATE-0 (cl≤2 分岐, 即着地だが大半既存)
- (a) cl≤2 = `Omega.pow_eq_one_of_class_le_two hp_odd hc2 hg` 一行 (CriticalSubgroup.lean:740)。
- (b) cl≤2 = `mul_pow_eq_commutator_pow_mul_of_central` + p∣C(p,2) (p odd) で ⁅y,x⁆^C(p,2)=1。
- ⚠ cl≤2 部分は既存 lemma の薄い再利用に近い (単独 theorem 化は wrapper 気味)。**価値は cl≤3**。

### GATE-1 ⭐ (4.4) full two-generator collection (cl≤3 の山場, gating, **最高リスク**)
目標: `mul_pow_eq_collect_of_triple_central (hc3: γ₃⊆Z) (hc4: γ₄=1) (u v) (n) :`
`(u*v)^n = u^n * v^n * ⁅v,u⁆^(n.choose 2) * ⁅⁅v,u⁆,u⁆^(FF n) * ⁅⁅v,u⁆,v⁆^(GG n)`
- **S1 γ₄=1 を hc3 と別に用意** (`hc4 : ∀ a b c d, ⁅⁅⁅a,b⁆,c⁆,d⁆=1`): cl≤3 = LCS₃=⊥ から導出 (小補題, constructible)。
- **S2 f/g 再計算 (確定バグ源・最重要)**: BG-literal f(n)=C(n,3), g(n)=2C(n,3)+C(n,2) を **mathlib convention (⁅a,b⁆=aba⁻¹b⁻¹) にそのまま転記すると誤り** (数値検証: BG-literal 624/1200 fail, mirror 0/1200)。n=2 base `mul_pow_two_eq_mul_commutator` (S04:410 = `u*⁅v,u⁆*u*v²`) に合わせ FF(2),GG(2),FF(3),GG(3) を decide で確定 → Pascal 漸化式 `FF(n+1)=C(n,2)+FF(n)` 型を mirror で書き直す。
- **S3 induction on n** ((uv)^{k+1}=(uv)^k(uv)): ih 代入 → 中心冪を右へ移す補正 (恒等式 (4.1) `[uv,w]=[u,w][u,w,v][v,w]` + Lem4.2 + hc4 で二次補正=0) → `v^k u v` 展開 (`pow_mul_eq_commutator_mul` S04:420 + `commutatorElement_pow_left_of_triple_central` S04:378) → 中心項集約 (`mul_central_pow_collect` S04:362) → FF/GG Pascal 畳み込み (`Nat.choose_succ_succ'`+`Nat.choose_two_right`)。
- ⚠ **hc3 だけでは S3 の二次補正が落ちず不足。hc4 必須** (precursor docstring S04:294 明記)。

### GATE-2 (b) cl≤3 ((4.4)|n=p, induction 不要)
(4.4) に n=p 代入。⁅y,x⁆,⁅y,x,x⁆,⁅y,x,y⁆ ∈ R'⊆Ω₁ かつ hc3/hc4 で互いに可換 ⇒ 生成部分群 abelian で pᵖ乗=1。
補正指数 C(p,2)(p odd で p∣), FF(p),GG(p)(=C(p,3),C(p,2) 整係数和, p>3 で p∣, `Nat.Prime.dvd_choose_self`) ⇒ 全補正項 = (⁅·⁆^p)^… = 1。残り xᵖyᵖ。
- 要小補題: 「R'≤Ω₁ ⇒ commutator 達の p乗=1」を abelian-subgroup 経由で。

### GATE-3 (a) cl≤3, p>3 (|R|-induction, **scaffold-trap 集中**)
Finite R で Nat.card R strong induction。x,y∈R, xᵖ=yᵖ=1。⟨x⟩=⊤ なら abelian で即。⟨x⟩≠⊤ ⇒ 極大 S⊇⟨x⟩ (`IsCoatom.normal_of_isPGroup` で S◁R)。IH で Ω₁(S) exp p ⇒ (4.5) ⁅y,x⁆^p=⁅y,x,x⁆^p=⁅y,x,y⁆^p=1 を**導出** (仮説 hoist 禁止) → (4.4)|n=p で (xy)^p=1。Ω₁ = closure なので `omega1OfClassLeThree : Subgroup` の mul_mem' に這わせ closure_le (CriticalSubgroup.lean:727 `omega1OfClassLeTwo` を mirror)。Ω₁(S)◁R は Omega.characteristic + char-in-normal⇒normal を subgroupOf 越しに配線。

## scaffold-trap (要警戒, design 監査より)
1. **(4.4) collection を仮説 hoist 厳禁** — induction で proved theorem に。
2. **f/g を BG-literal のまま使うな** — mathlib convention で再計算 (誤 f/g を仮説に隠すと vacuous-shaped で build を通る罠)。
3. (4.5) ⁅·⁆^p=1 を仮説 hoist 禁止 — |R|-induction の結論から導出。
4. (a) 結論を single-element/cyclic/vacuous に弱化禁止 — product-closure (xᵖ=yᵖ=1⇒(xy)ᵖ=1) が真の内容、Ω₁=closure を closure_le で。
5. S が cl≤3 を満たすことの R→S 降下を per-subgroup 仮説 hoist 禁止 — 新規補題で導出 (`commutator_le_center_of_le_of_class_le_two` cl≤2版を雛形に)。
6. litmus: 完成 theorem の全仮説を hcl + Fact p.Prime/Odd p/Finite R/IsPGroup p R *だけ*から instantiate できること。
