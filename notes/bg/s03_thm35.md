## ステートメント

> **BG Theorem 3.5**: `G = KR` を Frobenius 群 (可解 Frobenius kernel `K`, 巡回 Frobenius complement
> `R` 素数位数 `p`)。`G` が体 `F` 上のベクトル空間 `V` に作用 (`char F ∤ |G|`)。**`C_V(R)` が
> 1 次元**なら `K' ⊆ C_K(V)`。

```lean
-- alg-closed core (induction の本体; WLOG F alg-closed は証明 step 1)
theorem thm35_algClosed {F} [Field F] [IsAlgClosed F] {G} [Group G] [Finite G]
    {V} [AddCommGroup V] [Module F V] [FiniteDimensional F V]
    (ρ : Representation F G V) (K R : Subgroup G)
    (hFrob : IsFrobeniusGroup G K R) (hKsolv : IsSolvable ↥K) (hRcyc : IsCyclic ↥R)
    (hRp : ∃ p, p.Prime ∧ Nat.card ↥R = p) (hchar : (Nat.card G : F) ≠ 0)
    (hCV1 : Module.finrank F (Representation.invariants (ρ.comp R.subtype)) = 1) :
    ∀ g ∈ ⁅(⊤ : Subgroup ↥K), ⊤⁆.map K.subtype, ρ g = 1  -- K' ⊆ C_K(V)
-- general F は base change で `thm35` として導く (Thm 3.4 の `thm34` と同型)
```

別途 `K'_subgroup : Subgroup G`。Thm 3.4 は `⁅R,K⁆` を直接使ったが、3.5 は `K'` が必要 — 表現を要検討
(Thm 3.6 が `[H,R]'` 等でどう消費するかに合わせる)。

2. **非 faithful 枝** (L909-913): `C = C_G(V) ≠ 1`。`K ⊆ C` なら `K'⊆C` 即終。`K ⊄ C` なら **Lemma 3.2**

3. **faithful 仮定** (L915, 残り全体)。⟹ `C_G(V)=1`、つまり任意の `N≤G` で `C_N(V)=1`。
4. **(3.4)** (L917-927): proper R-inv subgroup `N<K` ⟹ `NR` が仮説満たす (`|NR|<|G|`) ⟹ IH で `N'⊆C_N(V)`。
   faithful ゆえ `C_N(V)⊆C_G(V)=1` ⟹ `N'=1` ⟹ **N abelian**。よって全 proper R-inv subgroup は abelian。
5. **K' abelian** (L929): K 可解 ⟹ `K'` proper characteristic ⟹ proper R-inv ⟹ (3.4) で abelian。
6. **(3.5) 二分律** (L931-939) [**tractable leaf, IH 不要**]: R-inv `N⊆K`, NR-submodule `U⊕W⊆V`
   (U,W NR-inv)。N が U に非自明作用 ⟹ Lem 3.3 で `C_U(R)≠0` ⟹ (1-dim) `C_V(R)=C_U(R)⊆U` ⟹
   `C_W(R)=C_V(R)∩W⊆U∩W=0` ⟹ Lem 3.3 対偶で N が W に自明。∴ **`U⊆C_V(N)` ∨ `W⊆C_V(N)`**。
   ⚠ plumbing: NR を Frobenius 部分群として組む (`N.subgroupOf NR`/`R.subgroupOf NR` + `centralizer_ne_bot`)。
7. **U 選択 + Maschke** (L941): faithful ⟹ K が非自明作用する irreducible G-submodule `U` が存在。Maschke で
   G-inv complement `W` (`V=U⊕W`)。(3.5) [N=K] で `W⊆C_V(K)⊆C_V(K')`。
8. **`C_U(K')≠0` ⟹ done** (L943): `C_U(K')≠0` なら `K'◁G` ゆえ submodule、U irreducible ⟹ `U=C_U(K')⊆C_V(K')`
   ⟹ `V=U⊕W⊆C_V(K')` ⟹ faithful で `K'=1`。∴ **`C_U(K')≠0` を示せば十分**。
9. **`C_U(K')≠0` の証明** (L945-951) [**hard core = 一般体 Clifford/Wedderburn**]:
   - U を K-module として: irreducible K-submodule M, R=⟨x⟩。**Clifford (G 3.4.1)**: `U=⊕共役M`,
     R が Wedderburn 成分を transitive に置換 ⟹ 成分数 = 1 or p。
     - **p 成分**: `U=M⊕Mˣ⊕…⊕Mˣ^{p-1}`, π₁ 射影。`Σ mxⁱ` は R-fixed ⟹ π₁(C_U(R))=M, C_U(R) 1-dim
       ⟹ M 1-dim K-module ⟹ `M⊆C_U(K')` ⟹ done。
     - **1 成分** (共役全 iso): **Prop 2.2** ⟹ `U_K≅M` (U irreducible K-module)。
   - U を K'R-module として: reducible なら (3.5) で `C_U(K')≠0`。⟹ U irreducible K'R-module と仮定。
   - U を K'-module として: Clifford ⟹ Wedderburn 成分。R が transitive (数∣p), K が transitive (数∣|K|),
     `gcd(p,|K|)=1` ⟹ 1 成分。**Prop 2.2** ⟹ U irreducible K'-module。
   - F alg-closed + K' abelian ⟹ **U 1-dim** ⟹ `U⊆C_U(K')` ⟹ `C_U(K')≠0`。done。
