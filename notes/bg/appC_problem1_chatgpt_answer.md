## 主張の核心 (= こちらで完全に再現・検証済 ✅)

witness `(G, σ, Q, y)` があるとして `g = x^y`, `c = x^{-1}g` とおく。すると

* `c ∈ Q` かつ `c^x ∈ Q`、`Q` は可換 ⟹ `[c, c^x] = 1`
* `g = xc` は位数 3 ⟹ `(xc)^3 = 1`
* `g` の `U ≅ C_n` への作用は `u ↦ u^e` (`e^3 ≡ 1 mod n`)

ゆえに `G = ⟨H, g⟩` は**万能完備化**

```
Γ_e = ⟨ H, z | [z, z^x] = 1, (xz)^3 = 1, (xz) u (xz)^{-1} = u^e ⟩
```

の商 (`z ↦ c`)。したがって **`Γ_e` で `z^3 = 1` が成り立てば、任意の witness で `c^3 = 1`**。
`c` は 3′-群 `Q` の元だから `c = 1`、つまり `g = x`。しかし `⟨g⟩ = σ(P₀)^y` は `σ(U)` を
正規化し `σ(P₀)` は正規化しない (`H` は Frobenius, `N_H(U) = U`) ので矛盾。
**`G` の有限性は一切使っていない。**

⚠ この論法の眼目は「`D = ⟨x,g⟩` を有限群のリストから探す」必要が消えること。
`[c,c^x]=1` と `g^3=1` だけを課した**普遍対象**を直接扱うので、こちらが 2026-08-09 に
やっていた `|D| ≤ 60` の枚挙 (24 ケース) は丸ごと不要になった。
