## I. 主張 (回答者が PROVED としたもの)

記法: `n = (Q−1)/2 = |U|`、`L = Fix_U(E) = {u ∈ U : u^{E−1} = 1}`、`a = |L| = gcd(E−1, n)`、
`c = [U:L]`、`X = {p : χ(p) = χ(p−1)} = T ⊔ T''`、`λ(p) = p/(p−1)`。

### 1. 点ごとの `E ↔ E²` 共役

`Φ_E(p) = p^E / D_E(p)` とすると `λ(Φ_E(p)) = λ(p)^E`、`Φ_E³ = 1`、`Φ_E` は `j(p) = 1−p` と可換。
`j`-軌道を `T` の代表で同一視すると位数 3 の置換 `Ψ_E : T → T` が得られ、

```
D_{E²}(Ψ_E(p)) = D_E(p)^{−E²}
```

⟹ **ファイバーサイズ分布が `E` と `E²` で完全に一致する** (衝突集合の全単射より強い、値ごとの一致)。
`Ψ_E` の不動点の個数は `(a−1)/2`。

### 2. Theorem A — (B1) の gcd 判定 (探索不要)

`E³ ≡ 1 (mod n)` と `gcd(E−1, E²+E+1) | 3`、`3 ∤ n` より **`a·c = n`**
(`c = gcd(E²+E+1, n)`)。`L` の剰余類 `C = uL` に対し
`T_C = {p ∈ T : p ∈ C, p−1 ∈ C}` と置くと、`p ∈ T_C` は `p^E = λ_C p`, `(p−1)^E = λ_C (p−1)`
(`λ_C = u^{E−1}`) を満たすので **`D_E(p) = λ_C`** — `T_C` の 2 点はすべて衝突。

数え上げ: 「`p` と `p−1` が同じ `L`-剰余類 ⟺ `p/(p−1) ∈ L`」で、`j` は `L` 上の反転に対応し
`|L|` は奇数だから `Σ_C |T_C| = (a−1)/2`。さらに `ι(p) = p/(p−1)` は `T_L` 上の**不動点を持たない
対合** (`ι(p) = p` は `p = −1 ∉ U`) なので `|T_L|` は偶数。⟹ すべての `T_C` が 1 点以下なら
`Σ ≤ c − 1`。よって

> **`(a−1)/2 ≥ c` (⟺ `a ≥ 2c+1` ⟺ `a(a−1) ≥ 2n` ⟺ `n ≥ 2c²+c`) ならば (B1) が成り立つ。**

`δ ∈ U` の条件は順序付けで自動 (`−1` が非平方)。

### 3. 同一剰余類の衝突の特別な形

`p, r ∈ T_C`、`h = r−p`、`λ = u^{E−1}`、`μ = u^{E²−1}` とすると `δ = λh`、
`K_E(p) = K_E(r) = −μ`、`μλ^{−E} = λ` より

```
S = S′ = −λ h^{−E}
```

`δ ∈ U` に向き付ければ `χ(S) = χ(−1)χ(λh) = −1` ⟹ **`S` は非平方**。

### 4. Theorem B — 同一剰余類の衝突は (B2) 無しで witness を排除

`K(p) = K(r)` なので関係式 (3) が**共役でなく交換関係**になる:
`[a(t), b(S t^E)] = 1` (∀`t ∈ F`)。ここで

```
W = {s ∈ F : [a(t), b(s t^E)] = 1 (∀ t ∈ F)}
```

は `F₃`-部分空間で `S ∈ W`。**`W` は `s ↦ s^{−E}` で閉じる** (関係式を `g²` で共役し、
`d(u) = a(−u^E) b(−u^{E²})` で `A` 側を消す) ⟹ 3 回反復して `s ↦ s^{−1}` で閉じる。

**補題 (反転で閉じた加法部分群)**: `W ≠ 0` が体 (標数 ≠ 2) の加法部分群で反転で閉じるなら、
`s ∈ W^×` に対し `K = s⁻¹W` は**部分体**。証明は Hua の恒等式
`x²y⁻¹ = x − (x⁻¹ + (y−x)⁻¹)⁻¹` で `v ∈ K ⟹ v² ∈ K`、`2uv = (u+v)²−u²−v²` で積閉包。

`F = 𝔽_{3^q}` (`q` 素数) の部分体は `𝔽₃` と `F` のみ ⟹ **`W = 𝔽₃` または `W = F`**
(`W = sF₃` のとき `s⁻¹ ∈ W` から `s² ∈ 𝔽₃^×`、`s² = −1` は `−1` 非平方ゆえ不可 ⟹ `s = ±1`)。

* `W = 𝔽₃` ⟹ `S` は非平方な `𝔽₃` の元 ⟹ **`S = −1`** ⟹ `Tr S = −q ≠ 0` ⟹ トレース障害 (P5)。
* `W = F` ⟹ `t = 1` で `x = a(1)` が `B` 全体を中心化 ⟹ `U`-共役で `A` が `B` を中心化 ⟹
  `N = AB` は可換 ⟹ **定理 2 (N は非自明完全) に矛盾**。

> **Theorem B: 同一剰余類の衝突が 1 つでもあれば witness は存在しない。(B2) は不要。**

### 5. Theorem C = A + B

`a = gcd(E−1,n)`, `c = gcd(E²+E+1,n) = n/a` として **`a ≥ 2c+1`** なら hypothesis (B) は不可能
(`G` の有限性不問、(B2) 不要)。gcd と整数比較だけの有限チェック。

### 6. Theorem D — (B2) そのものの十分条件

`p−1, p, p+1 ∈ L` なる `p` があれば `r = p+1` として `D(p) = D(r) = 1`, `δ = 1`, `K(p) = −1`
⟹ `Tr(K δ^{−E}) = Tr(−1) = −q ≠ 0`。個数 `N₃` を `k = 2c` 個の乗法指標で展開し Weil 評価すると


⟹ **`Q − 3 > 2(k³−1)√Q`** (⟺ `(Q−3)² > 4Q((2c)³−1)²`) なら (B2) が成り立つ。
