## 1. mmd L1789-1967 本文の精読結果 (前半部)

### narrow の正式定義 (§5 L1789 冒頭、§1 L354 が正本)

> "a p-group R [is] *narrow* if r(R) ≤ 2 **or** if R contains a subgroup R₀ of order p
> such that C_R(R₀) = R₀ × R₁ for some cyclic subgroup R₁ of R."

Lean def: `r(R) ≤ 2` を `pRank R p ≤ 2` で、`C_R(R₀) = R₀ × R₁` は
`R₀ ⊓ R₁ = ⊥` + `centralizer = R₀ ⊔ R₁` + `IsCyclic R₁` で表す。
`Subgroup.IsComplement' R₀ R₁` は ambient `R` で `R₀ ⊔ R₁ = ⊤` を要求するので使わない。
(注: `r(R) ≤ 2` ⟺ "no E_{p³}" は Lem 4.7 で同値だが**非自明**。定義は素朴形 `pRank ≤ 2`
を採る。Thm 5.3/Cor 5.4 が rank≥3 での同値刻画を与えるので定義はこれで十分。)

### `E²(R)`, `E*(R)`, `E²∩E*` の意味 (Thm 5.3 L1838 が明示)

- `E²(R)` = 位数 p² の elementary abelian 部分群。
- `E*(R)` = **maximal** elementary abelian (no larger elem-ab に含まれない)。
- `E²(R)∩E*(R)` = "位数 p² だが位数 p³ の elem-ab に含まれない" 元 (Thm 5.3 の括弧書き)。

### Lem 5.1 proof (L1795-1806) の構造

- (a) = "follows from Lemma 4.7" — **Lem 4.7⇒ の別名そのもの**。
- (b): (a) と **Lem 1.22** で normal `B`(位数 p³)を取り、`B* = E·C_B(E)`。`B*` elem-ab かつ
  `B* ⊴ R`。`|B*| ≥ p³` なら Prop 4.4 で SCN₃ 元へ拡大して終わり。`|B*| < p³` なら
  `B* = E`, `E ⊇ C_B(E)`、`|E|=p²` から `|C_B(E)| ≥ p²` かつ `C_B(E) = E ⊊ B`、`B` abelian
  なので `B = C_B(E)`、矛盾。

### Lem 5.2 proof (L1808-1836) の構造 (★山場)

`Z=Ω₁(Z(R))`, `W=Ω₁(Z₂(R))`, `T=C_R(W)`。`E∈E²∩E*`:
- `EZ` elem-ab かつ `E∈E*` ⇒ `EZ=E` ⇒ `Z⊆E`。similar argument で `r(C_R(E))=2`。⇒ `(5.1)`: `Z⊂E`, `|Z|=p`。
- **Lem 4.5(c)** で `W` noncyclic exp p。⇒ `(5.2)`: `Z⊂W`, `[W,R]=[Ω₁(Z₂),R]∩W⊆Ω₁(Z(R))=Z`。
- `[E,W]⊆[R,W]⊆Z⊂E` ⇒ `W` normalizes `E`。`C_W(E)` exp p + `E∈E*` ⇒ `C_W(E)⊆E`。`Z⊆C_W(E)⊆E`。
- `C_W(E)=E` なら `[E,R]⊂E` ((5.2)(5.1))、よって `E⊴R`、**Lem 5.1(b) より** `E∉E*`、矛盾。
  よって `C_W(E)=Z`。
- `1<|W/Z|=|W/C_W(E)|`。`|E|=p²` かつ `W/C_W(E) ↪ p-subgroup of Aut E` ⇒ `|W/Z|=p`, `|W|=p²`。((a)(b) 完了)
- 同論法繰返しで `|R/T|=|R/C_R(W)|=p`。`T char R` 明らか。((c) 完了)

### Thm 5.3 proof (L1838-1873) の構造 (★山場 延長)

- (⇒) narrow ⇒ `R₀` (位数 p, `C_R(R₀)=R₀×R₁`) 取り、`r(C_R(R₀))≤2<3≤r(R)` から `R₀⊄Z`,
  `R₀∩Z=1`、`R₁≠1`、`E=Ω₁(C_R(R₀))=R₀×Ω₁(R₁)∈E²∩E*`。Lem 5.2 で (a)(b)(c)。
  (d): `S`(位数p, `r(C_R(S))≤2`)で `S∩Z=1`、`SZ∈E²`、`r(SZ)≤r(C_R(S))≤2` ⇒ `SZ∈E*`。
  (a) で `SZ⊄T`。`Z⊆T`, `R'⊆T` ⇒ `S∩T=S∩R'=1`、`R=ST`, `C_R(S)=S×C_T(S)`。(5.3) で
  `r(C_T(S))=1`、Lem 4.5 で `C_T(S)` cyclic。
- (⇐) `E∈E²∩E*` ⇒ `Z⊂E`、`E=Z×S`、`E∈E*` から `2=r(C_R(E))=r(C_R(S))`、前段論法で
  `C_R(S)=S×C_T(S)` cyclic ⇒ narrow。

### Cor 5.4 proof (L1875-1879)

`r(R)≥3`: narrow ⇒ def の `R₀` で `r(C_R(R₀))≤2`。逆: `S`(位数p, `r(C_R(S))≤2`)で `S⊄Z`,
`r(SZ)>r(S)=1` ⇒ `SZ∈E²∩E*`、Thm 5.3 で narrow。

**注**: Cor 5.4 の両向きは Thm 5.3 (の ⇐ と (d) の論法)に強く依存。Thm 5.3 が deferred
である以上 **Cor 5.4 も deferred**。

### S5-0a `IsNarrow` 述語 — tractability: easy

**file**: `OddOrder/GroupTheory/NarrowPGroup.lean` / **module**: `OddOrder.GroupTheory.NarrowPGroup`

```lean
/-- **BG narrow p-group** (§1 p.2 / §5 p.44). For an odd prime `p`, a `p`-group `R`
is *narrow* iff `r(R) ≤ 2` (`pRank R p ≤ 2`) or there is an order-`p` subgroup `R₀`
whose centralizer is generated by `R₀` and a cyclic subgroup `R₁`, with
`R₀ ∩ R₁ = 1` (BG `C_R(R₀) = R₀ × R₁`). -/
def IsNarrow (p : ℕ) (R : Type*) [Group R] : Prop :=
  pRank R p ≤ 2 ∨
    ∃ R₀ R₁ : Subgroup R, Nat.card R₀ = p ∧ IsCyclic R₁ ∧
      R₀ ⊓ R₁ = ⊥ ∧ Subgroup.centralizer (R₀ : Set R) = R₀ ⊔ R₁
```
skeleton: 純 def。`Subgroup.IsComplement' R₀ R₁` は ambient `R` で
`R₀ ⊔ R₁ = ⊤` を要求してしまい、BG の `C_R(R₀)=R₀×R₁` より強すぎるので使わない。
centralizer 内部の直積性は `R₀ ⊓ R₁ = ⊥` と `centralizer = R₀ ⊔ R₁` で表す。基本補題として
`isNarrow_of_pRank_le_two : pRank R p ≤ 2 → IsNarrow p R := Or.inl` だけ付ける。
deps: `pRank` (PRank.lean), `IsCyclic` (mathlib)。

### S5-0b `IsMaximalElementaryAbelian` (= E*(R)) 述語 — tractability: easy

**file/module**: 同上

```lean
/-- **`E*(R)`: maximal elementary abelian subgroup** (BG §5 p.45). `E ≤ R` is
`p`-elementary abelian and is contained in no strictly larger elementary abelian
subgroup of `R`. -/
def IsMaximalElementaryAbelian (p : ℕ) {R : Type*} [Group R] (E : Subgroup R) : Prop :=
  E.IsElementaryAbelian p ∧
    ∀ F : Subgroup R, F.IsElementaryAbelian p → E ≤ F → F = E
```
補題 (本物で建つ):
```lean
theorem IsMaximalElementaryAbelian.isElementaryAbelian
    {p : ℕ} {R : Type*} [Group R] {E : Subgroup R}
    (h : IsMaximalElementaryAbelian p E) : E.IsElementaryAbelian p := h.1

/-- E* の sup 安定: F elem-ab かつ E ≤ F ⇒ F = E (maximality の言い換え). -/
theorem IsMaximalElementaryAbelian.eq_of_le

    (h : IsMaximalElementaryAbelian p E) (hF : F.IsElementaryAbelian p)
    (hEF : E ≤ F) : F = E := h.2 F hF hEF
```
skeleton: 純 projection。`E²∩E*` は `Nat.card E = p^2 ∧ IsMaximalElementaryAbelian p E`
で表す (専用 abbrev は作らず、現場で連言)。
deps: `Subgroup.IsElementaryAbelian` (ElementaryAbelian.lean)。
