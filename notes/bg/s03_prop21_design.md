# Prop 2.1 (Burnside) design — enveloping algebra = `End_F V` for abs. irreducible (2026-06-07)

Loop Step 0 output. Target (`AbsolutelyIrreducible.lean`, currently empty skeleton):

**Prop 2.1 / Burnside**: `F` alg-closed, `V` fin-dim `F`-space, `ρ : Representation F G V`
irreducible (⇒ `V` a simple `F[G]`-module). Then the **enveloping algebra** `E(G)` = the
`F`-subalgebra of `End_F V` generated by `ρ '' G` is **all of `End_F V`**; equivalently the
algebra hom `F[G] →ₐ[F] End_F V` is **surjective**.

(BG Thm 2.5 uses it as `E(P) = Hom_F(V,V)` for faithful irreducible `V` of extraspecial `P` over
alg-closed `F`. Faithfulness is not needed for surjectivity — irreducibility suffices.)

## Route (via Wedderburn–Artin over alg-closed — NO separate Jacobson density needed)

1. **Bridge** `Representation.irreducible_iff_isSimpleModule_asModule` (mathlib
   `RepresentationTheory/Irreducible.lean:34`): `IsIrreducible ρ ↔ IsSimpleModule F[G] ρ.asModule`.
2. **Algebra hom** `φ : F[G] →ₐ[F] End_F V` (= `Representation.asAlgebraHom ρ` / `MonoidAlgebra.lift`;
   VERIFY exact name). `A := φ.range : Subalgebra F (End_F V)` = the enveloping algebra.
3. **`A` is semisimple**: `F[G]` is semisimple (Maschke, `char ∤ |G|`; VERIFY mathlib
   `MonoidAlgebra.IsSemisimpleRing` / via `Module.Semisimple`). `A` is a quotient of `F[G]` (image
   of `φ`), so semisimple by `RingHom.isSemisimpleRing_of_surjective` (`SimpleModule/Basic.lean:469`).
4. **`A` is simple**: `V` is a faithful simple `A`-module (faithful: `A ⊆ End_F V` acts by eval, no
   nonzero element kills all of `V`; simple: subrep over `A` ⊇ subrep over `F[G]` ... actually `V`
   simple over `F[G]` ⇒ simple over the larger `A`? `A`-submodules ⊆ `F[G]`-submodules since `A` is a
   quotient acting through the same maps — VERIFY: `A`-stable = `F[G]`-stable, same operators). A
   **semisimple ring with a faithful simple module is simple** (it has a unique simple factor).
   [GAP: find/prove `IsSemisimpleRing A → IsSimpleModule A V → FaithfulSMul A V → IsSimpleRing A`.
   Likely route: semisimple ⇒ product of matrix rings; faithful simple ⇒ only one factor.]
5. **Wedderburn alg-closed**: `IsSimpleRing.exists_algEquiv_matrix_of_isAlgClosed F A`
   (`SimpleModule/IsAlgClosed.lean:22`) ⇒ `A ≃ₐ[F] Matrix (Fin n) (Fin n) F`, `n ≠ 0`.
6. **Dimension count**: `finrank F A = n²`. `V` is the (unique) simple `A`-module ≅ `Fⁿ`, so
   `finrank F V = n` (VERIFY via the matrix algebra's simple module dim). `finrank F (End_F V) =
   (finrank F V)² = n²`. `A ≤ End_F V` (subalgebra) with equal finrank ⇒ `A = End_F V`
   (`Submodule.eq_of_le_of_finrank_le` / `eq_top`).
