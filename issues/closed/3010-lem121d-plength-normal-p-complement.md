# BG Lem 1.21(d): p-length one ⟺ ⟨p-elements⟩ が normal p-complement を持つ

## 背景

BG §1 の唯一の残 numbered result (survey L289: 「Lem 1.21(a)(b)(c)(e) は済、(d) が gap、
never consumed downstream」)。§1 で document 順の最上流残。Lem 1.21(a)(b)(c)(e) は
`PLengthTransfer.lean` に済 (`HasPLengthOne`)。

## statement (BG mmd L569)

> (d) `G` has `p`-length one iff the subgroup `U` of `G` generated by all `p`-elements has a
> normal `p`-complement.

## ⚠ scope 訂正 (survey の「effort S」は楽観的; ⟨p-elements⟩ が repo 未実装)

**重要**: repo の `OPrime p G` (`Isaacs/Ch05_Transfer/Basic.lean:922`) は **index = p^k**
= `O^p(G)` (p-residual)。Lem 1.21(d) の `U = ⟨p-elements⟩ = O^{p'}(G)` (p'-residual、
index coprime to p) は**別物で repo 未実装**。mathlib に `IsPElement` も無い。よって新規に
`U` を定義する必要がある。

## 形式化計画

- **U の定義**: `U := Subgroup.closure {g : G | IsPGroup p (Subgroup.zpowers g)}`
  (= p-power order 元で生成) or `closure {g | orderOf g = 1 ∨ ∃ k, orderOf g = p^k}`。
  normal (characteristic; conjugation は p-element を p-element に送る)。
- **既存 infra**: `HasPLengthOne p G := oPiPrimePiPiPrimeCore {p} G = ⊤`
  (`S01_Solvable.lean:1277`)。bridge `hasPLengthOne_iff_card_quotient`
  (`PLengthTransfer.lean:54`): `HasPLengthOne p G ↔ ¬ p ∣ |G / O_{p',p}(G)|`
  (= `G/O_{p',p}(G)` は p'-group)。`HasNormalPComplement p G`
  (`Ch05_Transfer/Basic.lean:97`)。`oPiCore` / `oPiPrimePiCore` API。
- **証明 (2 段の iff)**:
  1. `HasPLengthOne p G ⟺ U ≤ O_{p',p}(G)`: bridge で `G/O_{p',p}` が p'-group
     ⟺ 非自明 p-element を持たない (Cauchy) ⟺ 全 p-element が O_{p',p} に入る
     ⟺ `U ≤ O_{p',p}(G)`。
  2. `U ≤ O_{p',p}(G) ⟺ HasNormalPComplement p ↥U`:
     - (⟹) `U ∩ O_{p'}(G)` が normal p-complement。`O_{p'} ◁ G` ゆえ `U∩O_{p'} ◁ U`、
       `U/(U∩O_{p'}) ≅ U·O_{p'}/O_{p'} ≤ O_{p',p}/O_{p'} = O_p(G/O_{p'})` = p-group、
       `U∩O_{p'} ⊆ O_{p'}` = p'-group ⟹ normal p-complement。
     - (⟸) normal p-complement `K` ◁ U ⟹ K char U ◁ G ⟹ K ◁ G, K p'-group
       ⟹ K ≤ O_{p'}(G)。`U/K` p-group ⟹ `U·O_{p'}/O_{p'}` は G/O_{p'} の normal
       p-subgroup ⟹ ≤ O_p(G/O_{p'}) = O_{p',p}/O_{p'} ⟹ U ≤ O_{p',p}(G)。
