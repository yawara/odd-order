## Statement (mmd L1221, subgroup 形式 = Thm 15.2 が使う形)

`G = KR` solvable odd, `K ⊴ G`, さらに
1. `(|R|, |K|) = 1` (coprime);
2. `∀ x ∈ R^#, C_K(x) = C_K(R)`;
3. `C_{F(K)}(R) = 1`。
⟹ `⁅K, R⁆ ⊆ F(K)`。

Lean 署名案 (subgroup 形式、Thm 15.2 適用に合わせる):
```
theorem thm38 {G : Type*} [Group G] [Finite G] [IsSolvable G]
    {K R : Subgroup G} [K.Normal] (hcompl : K.IsComplement' R)
    (hodd : Odd (Nat.card G))
    (hcop : Nat.Coprime (Nat.card ↥R) (Nat.card ↥K))
    (hC2 : ∀ x : ↥R, x ≠ 1 →
      Subgroup.centralizer ({(x:G)} : Set G) ⊓ K = Subgroup.centralizer (R : Set G) ⊓ K)
    (hC3 : Subgroup.centralizer (R : Set G) ⊓ fittingInG K = ⊥) :  -- C_{F(K)}(R)=1
    ⁅K, R⁆ ≤ fittingInG K
```
(`fittingInG K` = ambient Fitting of K; Thm 15.2 は K=M_σ, R=K(κ) で `[M_σ,K]⊄F(M_σ)` の contrapositive
に使う。⟹ 実際の Thm 15.2 適用形 = `¬(⁅K,R⁆≤F(K)) → C_{F(K)}(R)≠1` でよい。)

## 証明 (mmd L1231-1259) — |RK| 帰納

**step 1 (base case)**: `K̄ = K/F(K)`。R が F(K̄) の全 Sylow を中心化 → R が F(K̄) 中心化 →
**Prop 1.4** (`actionCommutator_eq_bot_of_fitting_le_fixedPoints`, S01:526) で R が K̄ 中心化 →
`⁅K,R⁆ ⊆ F(K)`。done。⟹ 以後「R が F(K̄) の Sylow p̄ を中心化しない p が存在」と仮定。

**step 2 (K̄ は p-群に reduce)**: P = preimage in K of P̄ (Sylow p of F(K̄))。P⊴K (F(K) char K +
P̄ char F(K̄))。F(P)=F(K) (両包含)。(3) が P で成立 (`C_{F(P)}(R)=C_{F(K)}(R)=1`)、(1)(2) も。
P≠K なら induction で `⁅P,R⁆⊆F(P)=F(K)` → R が P̄ 中心化、矛盾。⟹ K=P、**K̄ は p-群**。

**step 3 (R は素数位数に reduce)**: R_0≤R 素数位数。(1)(2)(3) が R_0 で成立 (式 L1239)。
R_0≠R なら induction で `⁅K,R_0⁆⊆F(K)`。**Prop 1.5(d)** (`coprime_fixedPoints_quotient`,
Isaacs Ch04:808) + (2) で `K̄ = C_{K̄}(R_0) = C_K(R_0)F(K)/F(K) = C_K(R)F(K)/F(K) = C_{K̄}(R)`
→ `⁅K,R⁆⊆F(K)`。done。⟹ 以後 **R 素数位数**と仮定。

**step 4 (chief factor core)**: W=U/V を `KR` の chief factor で `U⊆F(K)` とする。F(K) nilpotent
ゆえ W は elem abelian q-群、`KR` の irreducible faithful module (over `KR/C_{KR}(W)`)。
- **Prop 1.5(d)**: `C_W(R) = C_U(R)V/V ⊆ C_{F(K)}(R)V/V = 1`。
- `(|K|,|R|)=1` + `C_{KR}(W)⊴KR` → `C_{KR}(W)⊆K` → `=C_K(W)`。**Prop 1.2**
  (`fitting_le_chiefFactorCentralizer`, S01:368) で `F(K)⊆C_K(W)` → `K/C_K(W)` は p-群。
- **q=p**: `C_W(K/C_K(W))≠1` (**Gorenstein 2.6.3** = mathlib `IsPGroup.center_nontrivial` 系;
  p-群が F_p-加群に nonzero fixed pt)。irreducibility → `W=C_W(...)` → `K=C_K(W)` →
  `⁅K,R⁆⊆C_K(W)`。
- **q≠p**: **Theorem 3.4** (`thm34`, S03d:1073, Representation 形式) で
  `⁅R,K⁆` が `K/C_K(W)` を中心化 → `⁅K,R⁆⊆C_K(W)`。
- 両 case で `⁅K,R⁆⊆C_K(W)`。全 chief factor で成立 → **Prop 1.2 reverse** (P. Hall, S01:392) で
  `⁅K,R⁆⊆F(K)`。done。
