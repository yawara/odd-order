# Pf (10.3): n が偶数 (hn2 = §10 (10.5) chain 全体の genuine 算術 gate)

## 背景

Peterfalvi (10.3) は `n = (d − δ)/w₁` が **偶数** (したがって `n ≥ 1` と合わせ `n ≥ 2`) であることを
主張する。この parity が §10 (10.5) Cauchy–Schwarz 論証の `n < 2` 矛盾に必須
(`cauchySchwarz_numeric` `S12_MaximalIII_IV_V.lean`)。

現状この事実は **未形式化**で、§10 (10.5) chain 全体が `hn2 : 2 ≤ n` を仮説として一律に担っている:
- `Hypothesis.muGridAlpha_tau_inner_self` / `muGridAlpha_tau1_zeta_eq_neg_n` / `muGridAlpha_tau_X_inner`
- grid-level `Hypothesis.tau_muGridAlpha_eq` (issue 1007, (10.5) Dade-image identity)
- params-level `alpha_tau_image` (issue 1007)

issue 1007 ((10.5) Dade-image identity) は完了済 (grid + params 両 sorry-free) だが、`hn2` だけが
唯一の genuine な (10.3) 算術 gate として残る。これを形式化すれば (10.5) chain が真に unconditional
((10.3) 入力に関して) になる。

注: chain が担う他の同種仮説は導出可:
- `hδpm : δ = ±1` ← `SignedIrreducibleDifferenceFamily.sign_eq` (column sign)
- `hζne : ζ.conj ≠ ζ` ← (1.1) `not_isReal_of_ne_trivial_of_odd_card'` (ζ 非自明既約 + |M| 奇)
- `hw1 : 3 ≤ w₁`, `3 ≤ w₂` ← `typePData_toTICyclicHypothesis ... |>.three_le_card_W1/W2`

これらと違い `n` の parity は数論的に非自明 (Peterfalvi 原典 (10.3) の証明を要確認)。
