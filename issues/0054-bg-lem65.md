## (c) 実装プラン (mmd L2070-2088)

**規約注意**: 現 statement の `H^g = H.map (MulAut.conj g)` = `gHg⁻¹` (hall_C と同規約)。BG 原文は
`g⁻¹Hg`。**`g=cu` (c 先頭) を得るには BG 規約 `g⁻¹Hg≤U` が素直** → statement を
`H.comap (MulAut.conj g) ≤ U` (= `g⁻¹Hg ≤ U`) に変更してから証明するのが吉 (要再検討)。

1. `g = k*v` (k∈K, v∈U) を `G=KU` (`K⊔U=⊤`, `Subgroup.normal_mul`) で取得。
2. `g⁻¹Hg ⊆ U` から `k⁻¹Hk ⊆ U`: `g⁻¹Hg = v⁻¹(k⁻¹Hk)v ⊆ U ⟹ k⁻¹Hk ⊆ vUv⁻¹ = U`。
3. `k⁻¹Hk ⊆ HK` (k∈K: `k⁻¹hk = h·[h⁻¹,k⁻¹]`, `[_,_]∈K`)。⟹ `k⁻¹Hk ≤ V := (H⊔K)⊓U`。`H ≤ V`。
4. **crux: ↥V 内 hall_C**。`A := H.subgroupOf V`, `B := (k⁻¹Hk).subgroupOf V`。
   - 両方 `IsHallSubgroup π ↥V` (π := `(Nat.card H).primeFactors`): `|A|=|B|=|H|` (subgroupOfEquivOfLe),
     `V = H(K∩U)` (Dedekind, H≤U) ⟹ `|V|=|H||K∩U|` (`|H⊔(K∩U)|·|H∩K∩U|=|H||K∩U|`, K∩U⊴U,
     `H∩K=⊥`) ⟹ index = `|K∩U| | |K|` は π'。
   - `hall_C` (`IsSolvable ↥V`) ⟹ `∃ w̄:↥V, A.map(conj w̄)=B` ⟹ `∃ w∈V, wHw⁻¹ = k⁻¹Hk`。
     w⁻¹ を取れば `w⁻¹Hw = k⁻¹Hk` (BG 規約)。
5. `w∈V=H(K∩U)`, `w=h₀c₀` (h₀∈H, c₀∈K∩U) ⟹ `w⁻¹Hw = c₀⁻¹Hc₀` (h₀ 相殺) ⟹ `c₀⁻¹Hc₀=k⁻¹Hk`。
6. `c := k*c₀⁻¹ ∈ K`。`c⁻¹Hc = c₀k⁻¹Hkc₀⁻¹ = c₀(c₀⁻¹Hc₀)c₀⁻¹ = H` ⟹ c が H を正規化。
7. `c∈C_K(H)`: ∀h∈H, `c⁻¹hc∈H` かつ `c⁻¹hc ≡ h (mod K)` (c∈K) ⟹ `c⁻¹hc·h⁻¹∈H∩K=⊥` ⟹ 中心化。
8. `u := c₀*v ∈ U` (c₀∈K∩U⊆U, v∈U)。`g = kv = (kc₀⁻¹)(c₀v) = c*u`。∎

必要 API: `Subgroup.subgroupOfEquivOfLe` (card 保存), Dedekind `H(K∩U)=HK∩U` (or 直接 card),
`Subgroup.card_..._sup_..._inf` (積位数), `hall_C` @↥V, `IsHallSubgroup` 構築, `inf_eq_bot_of_coprime_card`。
推定 ~150-220 行。難所 = ↥V への持ち上げ (subgroupOf / map subtype 往復) と index の π' 判定。
